# Глоссарий Agent-Nutri Pro

> Словарь терминов, аббревиатур и понятий, используемых в проекте. Включает архитектурные термины, медицинские понятия, лабораторные показатели и обозначения школы нутрициологии.

**Версия:** 1.0
**Дата:** 2026-05-22

Термины сгруппированы по разделам. Внутри раздела — по алфавиту (русский алфавит, затем латиница и аббревиатуры).

## 1. Архитектурные термины проекта

**Агент (Agent-Nutri Pro)** — ИИ-система на базе Claude, генерирующая нутрициологические консультации по командам из `AGENT.md`. Не приложение, а структурированная база инструкций и знаний, которую Claude использует при работе с репозиторием.

**База знаний** — совокупность фактических данных, на которых агент основывает выводы. Физически — папки `references/`, `text_extracted/`, `source_files/`, частично `project/`. Противопоставляется операционной системе.

**Брифинг** — файл `CLAUDE.md` в корне репозитория. Первый файл, который читает Claude при входе; задаёт порядок чтения остальных файлов и базовые правила.

**Кластер** — тематический блок материалов школы, объединённый общей темой. В `project/MATERIALS_MAP.md` определены 10 кластеров: пищеварительная система, гепатобилиарная, лабораторная диагностика, щитовидка, метаболизм/вес, микронутриенты, женское здоровье, аутоиммунные состояния, антипаразитарные протоколы, инструменты работы. Обработка ведётся кластер за кластером.

**Команда агента** — директива из `AGENT.md`, начинающаяся со слэша: `/consult`, `/client`, `/compare`, `/menu`, `/intake`, `/links`, `/correct`, `/learn`. Каждая команда имеет свой пайплайн.

**Операционная система** — совокупность правил и логики работы агента. Физически — папки `v2/`, `skills/`, `learning/` и файлы `AGENT.md`, `RULES.md`, `CLAUDE.md`. Противопоставляется базе знаний.

**Пайплайн (pipeline)** — пошаговый алгоритм выполнения команды, описанный в `v2/PIPELINES.md`. Например, `/consult` имеет 9 шагов: чтение профиля → конвертация единиц → анализ показателей → выявление паттернов → дифференциальная диагностика → подбор нутрицевтиков → сборка отчёта → сохранение → коммит.

**Профиль клиента** — файл `clients/[Фамилия]/profile.md`. Содержит обязательные поля: пол, возраст, рост, вес, жалобы, активность, лекарства, диагнозы, курение, алкоголь, (для женщин) менструальный цикл.

**Скилл (skill)** — атомарный навык агента, описанный в `skills/[название].md`. Скилл реализует один логический шаг, который может вызываться из нескольких пайплайнов. Примеры: `analyze_blood.md`, `unit_conversion.md`, `recommend.md`.

**Слой истины** — категория знаний в новой структуре `references/`. Четыре слоя: `biochemistry/` (как устроены процессы), `clinical_guidelines/` (что говорит мировая медицина), `methodology/` (как работает школа), `personal_practice/` (как работает конкретный нутрициолог).

**Старый слой / Новый слой `references/`** — две параллельные структуры внутри папки `references/`. Старый слой — 14 плоских файлов с префиксами 01-13 (апрель 2026). Новый слой — четыре подпапки с категориями знаний (май 2026). Сосуществуют в переходный период, см. ARCHITECTURE.md раздел 4.

**Строгий режим (strict)** — режим выполнения команды, в котором агент не использует fallback и обязательно требует все входные данные. Применяется по умолчанию для `/consult` и `/client`.

**Режим fallback** — режим, в котором агент при отсутствии данных подставляет разумные допущения с явной пометкой. Включается только по явному запросу пользователя.

**Три уровня референсов** — концепция градации норм для лабораторных показателей, принятая в `references/methodology/tables/lab_values_master.md`. Уровень 1 (🔵 лабораторный референс) — диапазон для 95% условно здоровых. Уровень 2 (🟡 клинический оптимум) — диапазон, минимизирующий риск болезни по гайдлайнам. Уровень 3 (🟢 функциональный оптимум) — диапазон максимального самочувствия по функциональной медицине и школе.

**Эталон (Level 1)** — файлы `1expert_style_example.md.txt` и `1client_style_example.md.txt` в корне. Образцы идеального стиля экспертного и клиентского отчётов. Высший приоритет в `v2/HIERARCHY.md`. Никогда не редактируются.

**ADR (Architecture Decision Record)** — формат документирования архитектурных решений. Планируется ввести в папку `docs/decisions/` (см. `ARCHITECTURE.md` раздел 6).

## 2. Источники и стандарты доказательной медицины

**ADA** — American Diabetes Association. Источник для нормативов глюкозы, HbA1c, диагностики диабета.

**AGA** — American Gastroenterological Association. Источник для гастроэнтерологических протоколов, в том числе AGA 2024 по железодефициту.

**BSH** — British Society for Haematology. Источник для протоколов железодефицитной анемии (BSH 2021) и других гематологических состояний.

**Endocrine Society** — международное эндокринологическое общество. Источник для гайдлайнов по витамину D (2024), тиреоидным состояниям.

**ESC/EAS** — European Society of Cardiology / European Atherosclerosis Society. Источник для липидных гайдлайнов (ESC/EAS 2025).

**ETA** — European Thyroid Association. Источник для тиреоидных нормативов и подходов к ТТГ.

**LabCorp** — крупная американская лабораторная сеть. Источник лабораторных референсов.

**Mayo Clinic** — медицинский центр и лабораторная сеть. Один из основных источников лабораторных норм в проекте.

**NICE** — National Institute for Health and Care Excellence (Великобритания). Источник клинических гайдлайнов по широкому спектру состояний.

**WHO** — World Health Organization. Источник для эпидемиологических нормативов, антропометрических стандартов, дефинций дефицитов (например, йод, витамин A).

**Минздрав РФ** — Министерство здравоохранения Российской Федерации. Источник официальных российских клинических рекомендаций.

**Гемотест, Инвитро** — российские лабораторные сети. Источник российских лабораторных референсов в единицах системы СИ.

**OptimalDX, Effect Doctors, Lamkin Clinic, Root Functional Medicine** — источники функциональной медицины. Используются для уровня 3 (функциональный оптимум).

## 3. Лабораторные показатели и расчётные индексы

**АЛТ (ALT, аланинаминотрансфераза)** — фермент печени. Маркер цитолиза гепатоцитов.

**АСТ (AST, аспартатаминотрансфераза)** — фермент печени и других тканей. Совместно с АЛТ оценивается через индекс де Ритиса.

**АТ-ТПО (anti-TPO)** — антитела к тиреоидной пероксидазе. Маркер аутоиммунного тиреоидита.

**АТ-ТГ (anti-TG)** — антитела к тиреоглобулину. Дополнительный маркер аутоиммунного тиреоидита.

**АТ-рТТГ (TRAb)** — антитела к рецептору ТТГ. Маркер болезни Грейвса (гипертиреоз).

**Гомоцистеин (Hcy)** — аминокислота, маркер нарушений метилирования и фолатно-B12 статуса. Единица измерения: мкмоль/л (часто путают с ммоль/л — это ошибка).

**ГГТ (GGT, гамма-глутамилтрансфераза)** — фермент, маркер холестаза, токсических нагрузок на печень, алкогольных поражений.

**Гематокрит (HCT)** — доля эритроцитов в объёме крови.

**Гемоглобин (HGB)** — основной белок эритроцитов, переносчик кислорода.

**Индекс де Ритиса** — соотношение АСТ/АЛТ. Норма около 1.0; >1.3 указывает на алкогольное поражение, <0.7 — на вирусный гепатит или ожирение печени.

**Коэффициент атерогенности (КА)** — (Общий холестерин − ЛПВП) / ЛПВП. Маркер сердечно-сосудистого риска.

**ЛПВП (HDL)** — липопротеины высокой плотности, "хороший холестерин".

**ЛПНП (LDL)** — липопротеины низкой плотности, "плохой холестерин".

**МАУ** — микроальбуминурия. Ранний маркер диабетической нефропатии.

**Мочевина (Urea)** — конечный продукт белкового обмена. Единица: ммоль/л (часто путают с мкмоль/л — это ошибка).

**МСН (MCH)** — среднее содержание гемоглобина в эритроците.

**МСНС (MCHC)** — средняя концентрация гемоглобина в эритроците.

**MCV** — средний объём эритроцита. Маркер типа анемии (микроцитарная <80, нормоцитарная 80-100, макроцитарная >100).

**ОАК** — общий анализ крови.

**ОЖСС (TIBC)** — общая железосвязывающая способность сыворотки.

**ОАМ** — общий анализ мочи.

**ПЛ (PLT, тромбоциты)** — клетки свёртывания крови.

**ПТИ / МНО (INR)** — показатели свёртывающей системы крови.

**РФМК** — растворимые фибрин-мономерные комплексы. Маркер активации свёртывания.

**СОЭ (ESR)** — скорость оседания эритроцитов. Неспецифический маркер воспаления.

**ТГ (TG)** — триглицериды.

**ТТГ (TSH)** — тиреотропный гормон. Главный скрининговый маркер функции щитовидной железы.

**Ферритин** — белок-депо железа. Главный маркер запасов железа в организме. Также острофазный реагент (повышается при воспалении).

**ХС (TC, общий холестерин)** — суммарный холестерин крови.

**ЦП** — цветовой показатель крови. Аналог MCH в относительных единицах.

**ALP (alkaline phosphatase, щелочная фосфатаза)** — фермент костей и желчных путей.

**CRP (С-реактивный белок)** — острофазный маркер воспаления.

**FT3 / FT4** — свободные фракции трийодтиронина и тироксина.

**HbA1c (гликированный гемоглобин)** — интегральный показатель глюкозы за 2-3 месяца.

**Holo-TC (голотранскобаламин)** — активная фракция витамина B12. Более чувствительный маркер, чем общий B12.

**HOMA-IR** — расчётный индекс инсулинорезистентности по формуле (Инсулин × Глюкоза) / 22.5. Норма <2.7; оптимум ≤1.4 (школа), <1.0 (функциональная медицина).

**MMA (метилмалоновая кислота)** — функциональный маркер дефицита B12. Повышается при истинном клеточном дефиците.

**rT3 (reverse T3, обратный T3)** — неактивная форма тиреоидного гормона. Повышается при стрессе, голодании, тяжёлых болезнях.

**TSAT (transferrin saturation, насыщение трансферрина)** — расчётный показатель: (Железо / ОЖСС) × 100%. Маркер транспортного железа.

## 4. Витамины, минералы, методология

**B12 (кобаламин)** — витамин, дефицит которого вызывает мегалобластную анемию и неврологические нарушения. Оценивается по общему B12, Holo-TC, MMA, гомоцистеину.

**B9 (фолат, фолиевая кислота)** — витамин, кофактор метилирования. Дефицит вызывает мегалобластную анемию.

**B6 (пиридоксин, PLP)** — кофактор многих ферментов, в том числе цикла метилирования.

**Витамин D (25-OH-D)** — измеряется в нг/мл (×2.5 → нмоль/л). Endocrine Society 2024: дефицит <20 нг/мл, недостаточность 20-29, оптимум ≥30. Школа: функциональный оптимум 60-90 нг/мл.

**MTHFR** — ген метилентетрагидрофолатредуктазы. Полиморфизмы (C677T, A1298C) могут снижать активность фермента и эффективность метилирования.

**Метилирование** — биохимический процесс переноса метильной группы, ключевой для синтеза ДНК, нейромедиаторов, детоксикации. Зависит от B12, B9, B6, бетаина, холина.

**Нутрицевтик** — биологически активная добавка к пище с заявленным терапевтическим действием.

**RBC-фолат / RBC-Mg** — концентрация фолата или магния внутри эритроцитов. Точнее отражает запасы в тканях, чем сывороточный показатель.

## 5. Школа нутрициологии и проектные обозначения

**АПК** — антипаразитарный курс. Протокол школы, описанный в материалах уроков 21-22 Ступени 2 и в `references/01_digestion_gastro.md` (старый слой) или будущем `references/methodology/protocols/antiparasitic.md`.

**КБЖУ** — калории, белки, жиры, углеводы. Расчёт обязателен для клиентского отчёта при наличии роста и веса.

**Клиентский отчёт (Client-стиль)** — формат вывода `/client`. Тёплый тон, без таблиц, полные термины (без аббревиатур), 8 обязательных разделов, длина 250-300+ строк. Полное описание — `RULES.md` §3.2.

**Ступень 1 / Ступень 2** — обозначение уровней обучения в школе нутрициологии. Ступень 1 — базовая (9 уроков), Ступень 2 — продвинутая (30 уроков). Материалы расписаны в `project/MATERIALS_MAP.md`.

**Чек-лист (ЧЛ)** — формат материалов школы, представляющий показатель/тему в виде структурированного списка с нормами и комментариями. Часто конфликтует со значениями из уроков (см. историю с ТТГ: Урок 7 даёт 0.8-2.5, ЧЛ даёт 1.5-2.5).

**Экспертный отчёт (Expert-стиль)** — формат вывода `/consult`. Профессиональный тон, аббревиатуры допустимы, 9 обязательных разделов, дифференциальная диагностика, обоснование нутрицевтиков. Полное описание — `RULES.md` §3.1.

**Урок 7 Ступени 1** — конкретный урок школы по лабораторной диагностике, ставший основой для черновика `project/_temp/lab_values_school_extract.md` и далее для `references/methodology/tables/lab_values_master.md`.

## 6. Технические термины и обозначения git

**Branch (ветка)** — рабочая ветка проекта. Основная: `copilot/build-v2-nutrition-agent-core`. Никогда не работаем в `main` напрямую.

**Commit message format** — формат сообщения коммита: `type(область): краткое описание`. Типы: `feat` (новая функциональность), `fix` (исправление), `chore` (рутина), `docs` (документация), `refactor` (рефакторинг без изменения поведения).

**Conventional Commits** — стандарт оформления коммитов, упомянутый в `CLAUDE.md`. Используется упрощённая русскоязычная версия.

**Keep a Changelog** — стандарт оформления `CHANGELOG.md` (https://keepachangelog.com). Используется в проекте.

**Strict / Fallback** — режимы выполнения команд агента, см. раздел 1.

**Untracked file** — файл, ещё не добавленный в git. Показывается командой `git status` под заголовком "Untracked files".

## Как дополнять глоссарий

Если в работе встречается новый термин, который требует пояснения для понимания консультаций или внутренней документации — добавь его в соответствующий раздел по алфавиту. После добавления — коммит с сообщением `docs(glossary): добавлены термины [перечисление]`.
