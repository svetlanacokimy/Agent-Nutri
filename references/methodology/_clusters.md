- `references/methodology/protocols/lab_diagnostics.md` — алгоритмы интерпретации (7 шагов)
- `references/clinical_guidelines/iron_deficiency.md` — клинические рекомендации
- `references/unit_conversions.md` — единицы измерения

**Обоснование:** Эти файлы используются всеми кластерами, не относятся ни к одному органу или системе, и обновляются по своей кадансе.

---

## 3. Правила нумерации

1. **Стабильность номеров.** Однажды присвоенный номер кластера не меняется. Если кластер закрыт или объединён — его номер не переиспользуется.
2. **Расширение.** Новые кластеры получают следующий свободный номер (12, 13, ...).
3. **Источник правды.** При несоответствии метаданных протокола, ROADMAP.md или STATUS.md — приоритет у этого файла (`_clusters.md`).
4. **Изменение названия.** Переименование кластера допустимо без изменения номера; фиксируется в Changelog ниже.
5. **Связь с протоколом.** Каждый методологический файл должен указывать в блоке `## Метаданные` поле `**Кластер:** N (Название)`, где N и название точно соответствуют этой таблице.
