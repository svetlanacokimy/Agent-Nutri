## 1. Философия школы

1. Питание = база. Без покрытия БЖУ нутрицевтика не работает.
2. Считаем КБЖУ, а не "ем интуитивно". Минимум 1–3 месяца контроля для понимания норм.
3. Идеальный вес по ИМТ — основа расчёта при недоборе или избытке массы тела.
4. Не падаем ниже 1200–1300 ккал/сут — гарантированное плато и сбой обмена.
5. Белок — приоритет №1; жиры — не урезаем ниже 1 г/кг; углеводы — регулятор.
6. Режим питания: 3 основных приёма + перекусы по типу тела.
7. Без вздутий и брожений на любом типе питания.

## 2. Расчёт калорийности

### 2.1. BMR (Mifflin-St Jeor)

**Формула:** Вес (кг) × 9.99 + Рост (см) × 6.25 − Возраст × 4.92 − 161

(для женщин; для мужчин: + 5 вместо − 161 — школа использует женский вариант как базовый, для мужчин корректируется)

### 2.2. Коэффициенты физической активности

| Активность | Коэффициент |
|---|---|
| Нет нагрузки | 1.2 |
| 2 тренировки/нед | 1.4 |
| 4–5 тренировок/нед | 1.46 |
| 5–6 тренировок/нед | 1.55 |
| 7 тренировок/нед | 1.63 |
| 2 тренировки/день | 1.72 |

**TDEE** = BMR × коэффициент активности = калории поддержки.

### 2.3. Цель

| Цель | Корректировка |
|---|---|
| Похудение | TDEE − 10…20 % |
| Поддержка | TDEE |
| Набор | TDEE + 10…20 % |

**Минимум:** 1200–1300 ккал/сут. Ниже — плато, потеря мышц, сбой щитовидки.

### 2.4. Энергетическая ценность макронутриентов

- Белки: 4 ккал/г
- Жиры: 9 ккал/г
- Углеводы: 4 ккал/г

## 3. Белки

### 3.1. Нормы (г на кг массы тела)

| Активность | Белок, г/кг |
|---|---|
| Сидячий образ | 1.2 |
| 2–3 тренировки/нед | 1.4–1.6 |
| 3–5 тренировок/нед | 1.8–2.0 |
| 5–7 тренировок/нед | 2.0–4.0 (только профспортсмены) |

**Лабораторный контроль:** общий белок крови 74–78 г/л (функциональный оптимум школы).

### 3.2. 10 незаменимых аминокислот

Валин, изолейцин, лейцин, лизин, метионин, треонин, триптофан, фенилаланин, гистидин, аргинин.

**Ключевая цепочка:** фенилаланин → тирозин → T3/T4, адреналин, дофамин, меланин.

### 3.3. Время переваривания белка в желудке

| Продукт | Время |
|---|---|
| Яйца | до 1 ч |
| Рыба, морепродукты | 1.5–2 ч |
| Птица | 2 ч |
| Мелкая чечевица | от 1.5 ч |
| Маш, крупная чечевица, горох | 1.5–2.5 ч |
| Фасоль, нут | 2.5–3 ч |
| Красное мясо | от 3 ч |
| Молочка | 1.5 ч |
| Орехи, грибы | 1.5–2 ч |

### 3.4. Распределение по приёмам

- **Завтрак, ужин:** лёгкие белки (яйца, рыба, морепродукты, творог).
- **Обед:** тяжёлые белки (красное мясо, птица, бобовые).
- Не смешивать растительный + животный белок в одном приёме (исключение: ложка сметаны в борщ с фасолью — допустимо).
- Не смешивать разные тяжёлые белки (бобовые + мясо, мясо + грибы).

### 3.5. Обработка

- Идеально — тушение.
- Обжарка до корочки разрушает аминокислоты.
- Обугливание = канцерогены (акриламид, ПАУ).

---

## 4. Жиры

### 4.1. Норма

**1 г/кг массы тела**, минимум ½ — растительные.

### 4.2. Омега-3

- Норма: 1 г/сут.
- При воспалении/АИЗ: 2 г/сут.
- Обязательно EPA + DHA в составе.
- **Противопоказание:** льняное масло при дисфункции щитовидной железы (содержит цианогенные гликозиды).

### 4.3. Источники

- **Полезные:** сливочное масло (натуральное), оливковое extra virgin, авокадо, орехи, жирная рыба, яйца.
- **Вредные:** трансжиры (маргарин, фастфуд), пережаренные масла, рафинированные растительные масла.

**Трансжиры = 0.** Связь с СДК, болезнью Альцгеймера, АИЗ.

---

## 5. Углеводы

### 5.1. Норма

| Активность | Углеводы, г/кг |
|---|---|
| Сидячий | 1.6–2.0 |
| 2–3 тренировки/нед | 1.6–2.0 |
| 3–5 тренировок/нед | 2.0–3.0 |
| 5–7 тренировок/нед | 3.0+ |

### 5.2. Соотношение

**90 % медленных + 5–10 % быстрых.**

- **Медленные:** гречка, киноа, бурый рис, овсянка (не быстрая), бобовые, овощи, цельнозерновой хлеб.
- **Быстрые:** фрукты, мёд, сухофрукты, белый рис, белый хлеб, сладости.

## 6. Сводная таблица БЖУ по тренировкам

| Тренировок/нед | Белок, г/кг | Жиры, г/кг | Углеводы, г/кг |
|---|---|---|---|
| 0 (сидячий) | 1.2 | 1.0 | 1.6–2.0 |
| 2–3 | 1.4–1.6 | 1.0 | 1.6–2.0 |
| 3–5 | 1.8–2.0 | 1.0 | 2.0–3.0 |
| 5–7 | 2.0–4.0 | 1.5 | 3.0+ |

**При недоборе или избытке массы:** считать на идеальный вес по ИМТ, не на фактический.

## 7. Режим питания

### 7.1. Количество приёмов по типу телосложения

| Тип | Основных | Перекусов |
|---|---|---|
| Эктоморф (вата) | 3 | 1–2 |
| Мезоморф (питта) | 3 | 1 |
| Эндоморф (капха) | 3 | 1 |

**Правило перекуса:** при голоде 3–4 балла, если до основного приёма ещё 2–3 ч. При голоде на 3 балла дома — начинаем готовить, не перекусываем.

### 7.2. Структура приёмов

- **Завтрак:** белок + сложные углеводы + жиры (плотный).
- **Обед:** тяжёлый белок + крупа/бобовые + овощи (главный по объёму).
- **Ужин:** лёгкий, веганский/вегетарианский (если завтрак и обед плотные). За 2–3 ч до сна, не позже 20:00.

### 7.3. Шаблоны ужинов

1. Гречка/киноа/безглютеновая лапша + овощи + рыба или морепродукты.
2. Рыба запечённая + овощи (брокколи, цв. капуста, кабачок) + свежий салат.
3. Фритатта с овощами и крупой.
4. Винегрет + омлет (1 целое яйцо + 3–4 белка).
5. Копчёная скумбрия + отварной картофель.
6. Рисовая лапша + брокколи + стручковая фасоль.
7. Грибы + салат + крупа.

## 8. Перекусы

### 8.1. Виды простых перекусов

1. Чай + горсть орехов (7–10 шт.) или сухофрукты.
2. Фрукты, ягоды.
3. Хлебец + паста из рыбы (форель, сайра, иваси, горбуша, треска, лосось, икра).
4. Хлебец + сливочное масло + твёрдый сыр (не при высоком холестерине).
5. Хлебец + хумус + огурец + салат.
6. Хлебец + авокадо-паста + яйцо пашот/отварное.
7. Сырая морковь (сладкая).

### 8.2. Орехи — нормы и обработка

**Норма:** горсть (7–10 шт.). Покупать по 300 г разных видов, чередовать.

**Замачивать или жарить:**

| Орех | Обработка |
|---|---|
| Миндаль | замачивать 2 ч или на ночь |
| Кедровые | замачивать 10–15 мин |
| Кешью | замачивать 10 мин+ (для майонеза — на ночь) |
| Чёрный кунжут | замачивать на ночь |
| Грецкий | обжаривать в духовке |
| Фундук | жарить |
| Бразильский | обжаривать в духовке |
| Фисташки | жарить |
| Семечки подсолнечника | жарить |
| Тыквенные семечки | жарить |
| Белый кунжут | жарить |

Замачивать только порцию на день — через сутки плесень.

### 8.3. Идеальные пары орех + сухофрукт

- Миндаль + финики
- Миндаль + курага
- Фундук + изюм
- Грецкий + изюм

**Едим отдельно от сухофруктов:** кедровые, фисташки, кешью, кокос, семечки подсолнечника, тыквенные.

**Сухофрукты замачивать** — становятся чистыми и сочными.

## 9. Вздутия и брожения — дифдиагностика

### 9.1. 12 причин

1. Сладкое после белковой еды (особенно после бобовых).
2. Не замачивание бобовых.
3. Плохое пережёвывание (даже смузи держать во рту).
4. Сладкие фрукты + сырые овощи в один приём.
5. Тяжёлый белок + картофельное пюре или мучное.
6. Смешивание разных тяжёлых белков (бобовые + мясо, мясо + грибы).
7. Запивание пищи холодной водой (спазм желудка).
8. Газированная вода после еды (открывает сфинктер Одди → недопереваренное в кишечник).
9. Переедание + сидячий образ жизни.
10. Резкий переход на новое питание (много бобовых/овощей/фруктов сразу).
11. Недостаточная выработка желчи.
12. Паразитоз.

### 9.2. Правило сладкого

Фрукты — **за 30–40 мин до еды** или **через 2–4 ч после** (по времени переваривания белка).

Сладкое переваривается за 30 мин. Если в желудке остался непереваренный белок — сладкое тянет его в тонкий кишечник → брожение → дуоденогастральный рефлюкс.

### 9.3. 3 вида вздутий (дифдиагностика)

| Тип | Локализация | Время | Причина | Действия |
|---|---|---|---|---|
| 1. После еды | низ живота | через 2–3 ч | неправильное сочетание | голод + вода + сорбент (уголь, энтеросгель) |
| 2. Утреннее натощак | верх живота | сразу при пробуждении | СИБР, дисбиоз | протокол урока 4 (кишечник) |
| 3. После хлебобулочных | вариативно | через 1–3 ч | непереносимость глютена или дрожжи | убрать глютен на 4–8 нед, восстановить ЖКТ, ввести пробно |

## 10. Вода

### 10.1. Норма

**30 мл × вес (кг)** — обычная норма.
**40 мл × вес (кг)** — при спорте и в жару.

Пример: 50 кг × 30 = 1500 мл/сут.

### 10.2. Режим

- После пробуждения: 1–2 стакана тёплой/комнатной воды (улучшает желчеотток, снимает ночное обезвоживание).
- До обеда — до 1 л.
- Остальное равномерно в течение дня.
- На столе всегда большой стакан (300 мл).

### 10.3. Две функции воды

1. **Транспортная:** разжижает кровь и желчь, доставляет нутриенты.
2. **Выделительная:** лимфа выводит токсины.

### 10.4. Признаки обезвоживания

- "Монетные столбики" эритроцитов (густая кровь).
- Тёмная моча (норма — прозрачная, слабо-жёлтая).
- Отёки (организм запасает воду).
- Запоры (густая желчь, плотные каловые массы).
- Головные боли.

### 10.5. Кофе

- **Норма:** 1 чашка/день, после завтрака (не натощак).
- После кофе — 1–2 стакана воды.
- 2–5 чашек/день → ↑кортизол → ↑эстрогены → доминирование эстрогенов (мастопатия, гиперплазия, эндометриоз, ПМС, рак груди).
- Кафестол → ↑холестерин (включая декаф).
- При высоком холестерине: отмена кофе на 2–6 мес.

### 10.6. Дифдиагностика голод vs жажда

Хочется "что-то съесть, но не знаешь что" → пить, не есть.

## 11. Цели — примеры расчёта

### 11.1. Похудение

**Пример:** женщина 80 кг, 160 см, 40 лет, 2 тренировки/нед.

- BMR = 80 × 9.99 + 160 × 6.25 − 40 × 4.92 − 161 = 799.2 + 1000 − 196.8 − 161 = **1441 ккал**.
- TDEE = 1441 × 1.4 = **2018 ккал** (поддержка).
- Цель −20 %: 2018 × 0.8 = **1615 ккал/сут**.
- Макросы (на 80 кг, 2 тренировки): белок 1.4 × 80 = 112 г (448 ккал); жиры 1.0 × 80 = 80 г (720 ккал); углеводы 1.6 × 80 = 128 г (512 ккал). Итого ≈ 1680 ккал.

### 11.2. Набор массы

**Пример:** женщина 50 кг, 165 см, 25 лет, сидячий образ.

- BMR = 50 × 9.99 + 165 × 6.25 − 25 × 4.92 − 161 = 499.5 + 1031.25 − 123 − 161 = **1247 ккал**.
- TDEE = 1247 × 1.2 = **1496 ккал**.
- Цель +20 %: 1496 × 1.2 = **1795 ккал/сут**.
- Макросы: белок 1.6 × 50 = 80 г (320 ккал); жиры 1.0 × 50 = 50 г (450 ккал); углеводы 5.1 × 50 = 257 г (1028 ккал). Итого ≈ 1800 ккал.

### 11.3. Правила корректировки

- Взвешивание раз в 10 дней (не после читмила).
- Пересчёт норм каждые 5 кг потери/набора.
- Плато: снизить до 800–1100 ккал на 3–5 дней (refeed-low) или поднять +10–20 % на 5–7 дней, потом вернуться в дефицит.
- Читмил: раз в 10 дней, +500 ккал, макросы не считаются.
- Постепенное увеличение белка: +20 % в неделю (не резко).

### 11.4. Частые ошибки

- Избыток жиров на завтраке (яйца + лосось + авокадо + масло сразу).
- Дефицит белка при избытке углеводов и жиров (сладкоежки).
- Резкие скачки макросов.
- Читмил без отслеживания веса.

## 12. Чек-лист для агента

При расчёте КБЖУ для клиента:

1. Уточнить: вес, рост, возраст, пол, активность (тренировок в неделю), цель (похудение/поддержка/набор).
2. Проверить ИМТ — если недобор/избыток, считать на идеальный вес.
3. Рассчитать BMR по Mifflin-St Jeor.
4. Умножить на коэффициент активности → TDEE.
5. Применить корректировку по цели (±10–20 %).
6. Проверить минимум: ≥ 1200–1300 ккал/сут.
7. Распределить макросы по таблице БЖУ (раздел 6).
8. Проверить общий белок крови (74–78 г/л) — если ниже, поднять белок до верхней границы нормы.
9. Назначить режим: 3 приёма + перекусы по типу телосложения.
10. Добавить водную норму (30 или 40 мл × вес).
11. Проверить чек-лист по вздутиям (раздел 9) — нет ли запретных сочетаний в текущем рационе.
12. Указать сроки контроля: взвешивание раз в 10 дней, пересчёт каждые 5 кг.

При наличии анемии или дефицита белка — кросс-ссылка на `iron_deficiency.md` (белок 1.5+ г/кг).
