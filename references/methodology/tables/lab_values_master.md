## 📚 КОНЦЕПЦИЯ ТРЁХ УРОВНЕЙ РЕФЕРЕНСОВ

При интерпретации анализов Агент-Нутри использует **три уровня** оценки результатов клиента:

### 🔵 Уровень 1 — Лабораторный референс (Lab Reference Range)
Диапазон, в который попадают **95% «условно здоровых» людей** популяции. Источники: Инвитро, Гемотест, LabCorp, Mayo, Quest.
**Смысл:** «не болен явно». НЕ означает «оптимально».

### 🟡 Уровень 2 — Клинический оптимум (Clinical Optimal Range)
Диапазон, при котором **минимизирован риск болезней** по данным крупных международных исследований. Источники: BSH, ASH, AGA, NICE, ETA, Endocrine Society, ВОЗ, Минздрав РФ.
**Смысл:** «низкий клинический риск».

### 🟢 Уровень 3 — Функциональный оптимум (Functional/Wellness Optimum)
Диапазон, при котором человек **чувствует себя максимально хорошо** и биохимические процессы работают на пике. Уровень функциональной медицины и российской школы нутрициологии. Источники: OptimalDX, Effect Doctors, школа российской нутрициологии (Урок 7 С1, Чек-лист).
**Смысл:** «максимум здоровья и качества жизни».

### ⚙️ Правило для Агента
1. При работе с клиентом — приоритезировать **Функциональный оптимум** (так работает школа).
2. Если результат вне референса → это явная проблема, ссылаться на клинический гайдлайн.
3. Если результат в референсе, но вне функционального оптимума → рекомендация нутрицевтической коррекции.
4. Всегда указывать **источник** и **уровень**, на котором сделана интерпретация.

## 1️⃣ ОБЩИЙ АНАЛИЗ КРОВИ (ОАК)

### 1.1 Гемоглобин (HGB, Hb)
- **Ед. изм.:** г/л (РФ) / g/dL (США); коэф. конверсии г/л × 0.1 = g/dL
- 🔵 **Лаб. референс:** женщины 120–140 г/л; мужчины 130–160 г/л (Инвитро)
- 🟡 **Клин. оптимум:** ВОЗ — анемия при <120 г/л (ж), <130 г/л (м); тяжёлая <80 г/л
- 🟢 **Функц. оптимум:** 125–140 г/л (ж), 140–155 г/л (м) — школа + OptimalDX
- **Источники:** [WHO 2011](https://www.who.int/publications/i/item/WHO-NMH-NHD-MNM-11.1), Урок 7 С1

### 1.2 Эритроциты (RBC)
- **Ед. изм.:** ×10¹²/л (= млн/мкл)
- 🔵 **Лаб. референс:** 3.5–5.3 (ж); 4.0–5.5 (м)
- 🟡 **Клин. оптимум:** референс
- 🟢 **Функц. оптимум:** 3.9–4.7 (ж); 4.5–5.2 (м) — школа

### 1.3 Лейкоциты (WBC) 🔄
- **Ед. изм.:** ×10⁹/л (= тыс/мкл)
- 🔵 **Лаб. референс:** 4.0–10.0
- 🟡 **Клин. оптимум:** <11 при отсутствии инфекции
- 🟢 **Функц. оптимум:** 4.5–7.5 — школа; ↑ при инфекции/стрессе, ↓ при вирусах/иммунодефиците
- **Источники:** [Mayo CBC](https://www.mayocliniclabs.com/test-catalog/overview/9109)

### 1.4 Гематокрит (HCT)
- **Ед. изм.:** % (= L/L × 100)
- 🔵 **Лаб. референс:** ж 36–46%; м 40–50%
- 🟡 **Клин. оптимум:** референс
- 🟢 **Функц. оптимум:** ж 36–44%; м 42–48% — школа

### 1.5 Средний объём эритроцита (MCV)
- **Ед. изм.:** фл (фемтолитр)
- 🔵 **Лаб. референс:** 80–100 фл
- 🟡 **Клин. оптимум:** 82–98 фл
- 🟢 **Функц. оптимум:** 85–92 фл — школа (87±5 фл); 📝 ↓ при ЖДА, ↑ при B12/фолат-дефиците

### 1.6 Среднее содержание Hb в эритроците (MCH)
- **Ед. изм.:** пг
- 🔵 **Лаб. референс:** 27–34 пг
- 🟡 **Клин. оптимум:** 27–33 пг
- 🟢 **Функц. оптимум:** 28–32 пг — школа

### 1.7 Средняя концентрация Hb в эритроците (MCHC)
- **Ед. изм.:** г/дл (РФ часто г/л)
- 🔵 **Лаб. референс:** 32–37 г/дл (= 320–370 г/л)
- 🟡 **Клин. оптимум:** референс
- 🟢 **Функц. оптимум:** 33–35 г/дл — школа

### 1.8 Ширина распределения эритроцитов (RDW)
- **Ед. изм.:** %
- 🔵 **Лаб. референс:** 11.6–14.8%
- 🟡 **Клин. оптимум:** <14.5% (↑ — ранний маркер дефицита железа/B12/фолатов)
- 🟢 **Функц. оптимум:** 11.5–13.5% — функциональная медицина (OptimalDX)

### 1.9 Тромбоциты (PLT)
- **Ед. изм.:** ×10⁹/л (= тыс/мкл)
- 🔵 **Лаб. референс:** 150–400 (Mayo, Cleveland Clinic); школа 200–400
- 🟡 **Клин. оптимум:** 150–400; ↓ риск кровотечений при <100
- 🟢 **Функц. оптимум:** 180–350 — школа
- **Источники:** [Cleveland Clinic PLT](https://my.clevelandclinic.org/health/diagnostics/21782-platelet-count)

### 1.10 Нейтрофилы (NEUT) %
- **Ед. изм.:** %
- 🔵 **Лаб. референс:** 48–78% (РФ); 40–60% (UCSF)
- 🟡 **Клин. оптимум:** 45–70%
- 🟢 **Функц. оптимум:** <60% — школа

### 1.11 Лимфоциты (LYM) %
- **Ед. изм.:** %
- 🔵 **Лаб. референс:** 19–37%
- 🟡 **Клин. оптимум:** 20–40% (UCSF)
- 🟢 **Функц. оптимум:** 23–37% — школа

### 1.12 Моноциты (MON) %
- **Ед. изм.:** %
- 🔵 **Лаб. референс:** 3–11%
- 🟡 **Клин. оптимум:** <10%
- 🟢 **Функц. оптимум:** <9% — школа; 📝 ↑ при хронических инфекциях, паразитах

### 1.13 Эозинофилы (EOS) %
- **Ед. изм.:** %
- 🔵 **Лаб. референс:** 1–5%
- 🟡 **Клин. оптимум:** <5%
- 🟢 **Функц. оптимум:** <3% — школа; 📝 ↑ при паразитах, аллергии, аутоиммунных

### 1.14 Базофилы (BAS) %
- **Ед. изм.:** %
- 🔵 **Лаб. референс:** <1%
- 🟡 **Клин. оптимум:** <1%
- 🟢 **Функц. оптимум:** <1% — школа

### 1.15 СОЭ (ESR) 🔄
- **Ед. изм.:** мм/ч (Вестергрен)
- 🔵 **Лаб. референс:** ж <20 мм/ч; м <15 мм/ч (StatPearls 2023)
- 🟡 **Клин. оптимум:** возрастная формула — ж: (возраст+10)/2; м: возраст/2
- 🟢 **Функц. оптимум:** 0–15 мм/ч — школа; 📝 ↑ — системное воспаление
- **Источники:** [StatPearls ESR](https://www.ncbi.nlm.nih.gov/books/NBK557485/)

---

### 📝 Комментарии к разделу 1 (ОАК)

**Опорные паттерны для Агента:**
- **ЖДА:** ↓Hb + ↓MCV + ↓MCH + ↑RDW → проверить ферритин (см. Раздел 5, Порция 2).
- **B12/фолат-дефицит:** ↑MCV + ↑MCH + норма/↓Hb → проверить B12, фолаты, гомоцистеин.
- **Паразитарная инвазия:** ↑эозинофилы + норма/↑моноциты + ↑СОЭ → серология паразитов (Раздел 11, Порция 4).
- **Хроническое воспаление:** ↑СОЭ + ↑моноциты + ↓лимфоциты + ↑тромбоциты → проверить СРБ, ферритин (как маркер воспаления).
- **Иммуносупрессия / вирус:** ↓лимфоциты + ↓нейтрофилы → клиническая оценка.

## 2️⃣ БИОХИМИЯ ОБЩАЯ (печень, белки, азотистый обмен)

### 2.1 АЛТ (ALT, аланинаминотрансфераза) 🆕
- **Ед. изм.:** Ед/л (U/L, IU/L)
- 🔵 **Лаб. референс:** ж <31; м <41 (Инвитро); Mayo 7–55
- 🟡 **Клин. оптимум:** <30 (LabCorp 2017 пересмотр); ↑ — повреждение гепатоцитов
- 🟢 **Функц. оптимум:** 10–25 Ед/л (OptimalDX функц. оптимум для метаболич. здоровья)
- **Источники:** [LabCorp ALT 2017](https://www.labcorp.com/assets/5286), [Mayo LFT](https://www.mayoclinic.org/tests-procedures/liver-function-tests/about/pac-20394595)
- 📝 Школьная таблица не выделяла АЛТ отдельно (есть только коэф. де Ритиса). Добавлено в master.

### 2.2 АСТ (AST, аспартатаминотрансфераза) 🆕
- **Ед. изм.:** Ед/л
- 🔵 **Лаб. референс:** ж <31; м <37 (Инвитро); Mayo 8–48
- 🟡 **Клин. оптимум:** <35
- 🟢 **Функц. оптимум:** 10–26 Ед/л — функциональная медицина
- 📝 ↑АСТ при норме АЛТ — миокард, мышцы (рабдомиолиз).

### 2.3 Коэффициент де Ритиса (АСТ/АЛТ)
- **Ед. изм.:** безразмерный
- 🔵 **Лаб. референс:** 0.9–1.3
- 🟡 **Клин. оптимум:** ~1.0
- 🟢 **Функц. оптимум:** ~1.0 — школа
- 📝 >1.3 — алкогольное поражение/цирроз; <0.7 — вирусный гепатит/НАЖБП.

### 2.4 ГГТ (GGT, гамма-глутамилтрансфераза)
- **Ед. изм.:** Ед/л
- 🔵 **Лаб. референс:** ж <38; м <55 (Инвитро); общий <50 (NHS)
- 🟡 **Клин. оптимум:** <40 Ед/л
- 🟢 **Функц. оптимум:** 10–17 Ед/л — OptimalDX (маркер оксидативного стресса и кардиометаболич. риска); школа <40
- **Источники:** [OptimalDX GGT](https://www.optimaldx.com/blog/ggt-much-more-than-a-liver-enzyme)
- 📝 ↑ГГТ — алкоголь, желчный застой, НАЖБП; чувствительный маркер.

### 2.5 Щелочная фосфатаза (ЩФ, ALP)
- **Ед. изм.:** Ед/л
- 🔵 **Лаб. референс:** ж 35–104; м 40–129 (Mayo)
- 🟡 **Клин. оптимум:** 40–90 Ед/л — школа
- 🟢 **Функц. оптимум:** 40–90 Ед/л
- 📝 ↑ — желчный застой, заболевания костей, дефицит цинка/B6 (если ↓).

### 2.6 Общий билирубин
- **Ед. изм.:** мкмоль/л (РФ) / mg/dL (США); коэф.: мкмоль/л × 0.0585 = mg/dL
- 🔵 **Лаб. референс:** 3.4–21 мкмоль/л
- 🟡 **Клин. оптимум:** <17 мкмоль/л
- 🟢 **Функц. оптимум:** <15 мкмоль/л — школа
- 📝 ⚠️ В Уроке 7 С1 встречалась опечатка «ммоль/л» — правильно мкмоль/л.

### 2.7 Прямой билирубин (конъюгированный)
- **Ед. изм.:** мкмоль/л
- 🔵 **Лаб. референс:** <5.1 мкмоль/л
- 🟡 **Клин. оптимум:** <5
- 🟢 **Функц. оптимум:** <3.4 — школа; 📝 ↑ — желчный застой.

### 2.8 Непрямой билирубин (неконъюгированный)
- **Ед. изм.:** мкмоль/л
- 🔵 **Лаб. референс:** <17.1 мкмоль/л
- 🟡 **Клин. оптимум:** <13
- 🟢 **Функц. оптимум:** <13 — школа; 📝 ↑ — гемолиз, синдром Жильбера.

### 2.9 Альбумин
- **Ед. изм.:** г/л (РФ) / g/dL (США); коэф. г/л × 0.1 = g/dL
- 🔵 **Лаб. референс:** 35–50 г/л (Mayo 35–50)
- 🟡 **Клин. оптимум:** 40–50 г/л
- 🟢 **Функц. оптимум:** 43–50 г/л — школа
- 📝 ↓ — печёночная недостаточность, нефротический синдром, белковый дефицит.

### 2.10 Общий белок
- **Ед. изм.:** г/л
- 🔵 **Лаб. референс:** 64–83 г/л (UCSF 60–83)
- 🟡 **Клин. оптимум:** 65–80 г/л
- 🟢 **Функц. оптимум:** 72–78 г/л — школа
- 📝 Важен для иммунитета, гормонов, ферментов.

### 2.11 Креатинин 🔄
- **Ед. изм.:** мкмоль/л (РФ) / mg/dL (США); коэф.: мкмоль/л × 0.0113 = mg/dL
- 🔵 **Лаб. референс:** ж 52–92 мкмоль/л; м 62–115 мкмоль/л (Mayo)
- 🟡 **Клин. оптимум:** в референсе, считать СКФ (eGFR ≥60 мл/мин/1.73м²)
- 🟢 **Функц. оптимум:** 44–97 мкмоль/л — школа; 📝 зависит от мышечной массы.
- **Источники:** [Mayo Creatinine](https://www.mayoclinic.org/tests-procedures/creatinine-test/about/pac-20384646)

### 2.12 Мочевина (Urea)
- **Ед. изм.:** ммоль/л (РФ) / mg/dL (США BUN); коэф.: ммоль/л × 2.8 = mg/dL BUN
- 🔵 **Лаб. референс:** 2.5–7.5 ммоль/л (Инвитро); 1.8–7.1 (NCBI)
- 🟡 **Клин. оптимум:** 2.8–7.2 ммоль/л (DiaSys)
- 🟢 **Функц. оптимум:** <5.5 ммоль/л — школа
- 📝 ⚠️ В школьной таблице опечатка: оптимум указан «<5.5 **мкмоль/л**» — правильно **ммоль/л**.
- **Источники:** [NIH Urea](https://www.ncbi.nlm.nih.gov/books/NBK305/)

### 2.13 Мочевая кислота
- **Ед. изм.:** мкмоль/л
- 🔵 **Лаб. референс:** ж 150–350; м 200–420
- 🟡 **Клин. оптимум:** <360 мкмоль/л (риск подагры выше при >360)
- 🟢 **Функц. оптимум:** <300 мкмоль/л — школа
- 📝 ↑ — подагра, метаболический синдром, инсулинорезистентность, фруктоза в избытке.

### 2.14 С-реактивный белок (СРБ, CRP)
- **Ед. изм.:** мг/л
- 🔵 **Лаб. референс:** 0–5 мг/л (РФ); 0–10 мг/л (некоторые лаб.)
- 🟡 **Клин. оптимум:** <3 мг/л (AHA — низкий кардиориск); <1 мг/л — оптимум
- 🟢 **Функц. оптимум:** <1 мг/л — школа; 📝 высокочувствительный (hs-CRP) для оценки кардиориска.

### 📝 Комментарии к разделу 2 (Биохимия)

**Опорные паттерны для Агента:**
- **НАЖБП (неалкогольная жировая болезнь печени):** АЛТ>АСТ + ↑ГГТ + ↑триглицериды + ↑HOMA-IR.
- **Алкогольное поражение печени:** АСТ>АЛТ (де Ритис >1.3) + ↑ГГТ.
- **Желчный застой:** ↑ЩФ + ↑ГГТ + ↑прямой билирубин.
- **Гемолиз:** ↑непрямой билирубин + ↓Hb + ↑ЛДГ + ↓гаптоглобин.
- **Скрытое воспаление:** ↑СРБ + ↑ферритин (как реактант) + ↑СОЭ → искать источник.
- **Белковый дефицит / мальабсорбция:** ↓альбумин + ↓общий белок + ↓мочевина.

## 3️⃣ ЛИПИДНЫЙ ПРОФИЛЬ

### 3.1 Общий холестерин (Total Cholesterol)
- **Ед. изм.:** ммоль/л (РФ) / mg/dL (США); коэф.: ммоль/л × 38.67 = mg/dL
- 🔵 **Лаб. референс:** <5.2 ммоль/л (<200 mg/dL) — Mayo, Инвитро
- 🟡 **Клин. оптимум:** <5.0 ммоль/л (ESC/EAS 2019/2025 для низкого риска); пограничный 5.0–6.2
- 🟢 **Функц. оптимум:** 4.1–5.2 ммоль/л (160–200 mg/dL) — школа <4.7; OptimalDX 4.14–5.15
- 📝 ⚠️ <4.0 ммоль/л + ↑hs-CRP — повышенный риск нейродегенеративных заболеваний и депрессии (избыточно низкий ХС вреден).
- **Источники:** [ESC/EAS 2025](https://www.atherosclerosis-journal.com/article/S0021-9150(25)01377-2/fulltext), [OptimalDX TC](https://www.optimaldx.com/blog/cholesterol-optimal-ranges-for-total-cholesterol-summary-0)

### 3.2 ЛПНП (LDL, «плохой холестерин»)
- **Ед. изм.:** ммоль/л / mg/dL
- 🔵 **Лаб. референс:** <3.3 ммоль/л (Инвитро)
- 🟡 **Клин. оптимум (ESC/EAS 2025):**
  - Низкий риск: <3.0 ммоль/л (<116 mg/dL)
  - Умеренный: <2.6 ммоль/л (<100)
  - Высокий: <1.8 ммоль/л (<70)
  - Очень высокий: <1.4 ммоль/л (<55)
- 🟢 **Функц. оптимум:** <2.6 ммоль/л — школа; функциональная медицина — 1.8–2.6
- **Источники:** [ESC/EAS 2025](https://www.atherosclerosis-journal.com/article/S0021-9150(25)01377-2/fulltext), [NCBI Cholesterol Guidelines](https://www.ncbi.nlm.nih.gov/books/NBK305897/)

### 3.3 ЛПВП (HDL, «хороший холестерин») 🔄
- **Ед. изм.:** ммоль/л / mg/dL
- 🔵 **Лаб. референс:** ж >1.2 ммоль/л; м >1.0 ммоль/л
- 🟡 **Клин. оптимум:** ж >1.3 ммоль/л (>50 mg/dL); м >1.0 ммоль/л (>40)
- 🟢 **Функц. оптимум:** >1.55 ммоль/л (>60 mg/dL) — школа; Hyman/Lustig (функц.мед.) >60 mg/dL
- 📝 ⚠️ Чрезмерно высокий ЛПВП (>2.5 ммоль/л) — обсуждается ассоциация с дисфункциональным холестерином; не всегда «лучше».

### 3.4 Триглицериды (TG)
- **Ед. изм.:** ммоль/л / mg/dL; коэф.: ммоль/л × 88.57 = mg/dL
- 🔵 **Лаб. референс:** <1.7 ммоль/л (Mayo, Medscape, ESC)
- 🟡 **Клин. оптимум:** <1.7 ммоль/л; пограничный 1.7–2.2; высокий >2.3
- 🟢 **Функц. оптимум:** <1.1–1.2 ммоль/л — школа <1.2; новые исследования: оптимум <1.09 ммоль/л для предотвращения СД2
- **Источники:** [Mayo TG](https://www.mayoclinic.org/diseases-conditions/high-blood-cholesterol/in-depth/triglycerides/art-20048186)
- 📝 ↑ТГ + ↑HOMA-IR + ↑ГГТ = метаболический синдром / НАЖБП.

### 3.5 Коэффициент атерогенности (КА)
- **Формула:** (Общий ХС − ЛПВП) / ЛПВП
- **Ед. изм.:** безразмерный
- 🔵 **Лаб. референс:** <3.5
- 🟡 **Клин. оптимум:** <3.0
- 🟢 **Функц. оптимум:** <2.5 — школа; <2.0 — оптимум
- 📝 Лучший предиктор кардиориска — соотношение ТГ/ЛПВП: оптимум <0.87 (mmol/L) или <2.0 (mg/dL).

### 📝 Комментарии к разделу 3 (Липиды)

**Опорные паттерны для Агента:**
- **Метаболический синдром:** ↑ТГ + ↓ЛПВП + ↑HOMA-IR + ↑окружность талии.
- **НАЖБП:** ↑ТГ + ↑АЛТ + ↑ГГТ + ↑ферритин + ↑HOMA-IR.
- **Семейная гиперхолестеринемия:** ЛПНП >4.9 ммоль/л + семейный анамнез ранних ССЗ — направить к врачу.
- **Гипотиреоз как причина дислипидемии:** ↑общий ХС + ↑ЛПНП + ↑ТТГ → проверить щитовидку (раздел 10, Порция 4).

## 4️⃣ УГЛЕВОДНЫЙ ОБМЕН

### 4.1 Глюкоза натощак (Fasting Glucose)
- **Ед. изм.:** ммоль/л (РФ) / mg/dL (США); коэф.: ммоль/л × 18 = mg/dL
- 🔵 **Лаб. референс:** 4.1–5.9 ммоль/л (Инвитро); ADA норма <5.6
- 🟡 **Клин. оптимум (ADA 2024):**
  - Норма: <5.6 ммоль/л (<100 mg/dL)
  - Предиабет: 5.6–6.9 (100–125)
  - СД: ≥7.0 (≥126)
- 🟢 **Функц. оптимум:** 4.5–5.0 ммоль/л — школа (Таблица 4.5–5.0; Чек-лист «до 5») ⚠️ внутреннее разночтение; принимаем **4.5–5.0**.
- **Источники:** [ADA 2024 Standards](https://diabetesjournals.org/care/article/49/Supplement_1/S27/163926/2-Diagnosis-and-Classification-of-Diabetes)

### 4.2 Гликированный гемоглобин (HbA1c)
- **Ед. изм.:** % (DCCT) / ммоль/моль (IFCC); коэф.: %=(IFCC+23.5)/10.93
- 🔵 **Лаб. референс:** <5.7% (ADA)
- 🟡 **Клин. оптимум (ADA 2024):**
  - Норма: <5.7%
  - Предиабет: 5.7–6.4%
  - СД: ≥6.5%
- 🟢 **Функц. оптимум:** <5.4% — школа; функциональная медицина 4.8–5.3%
- 📝 Отражает средний сахар за 90–120 дней. ⚠️ Может занижаться при гемолизе, дефиците железа (ложно завышается).
- **Источники:** [ADA A1C](https://diabetes.org/about-diabetes/a1c)

### 4.3 Инсулин натощак (Fasting Insulin) 🔄
- **Ед. изм.:** мкЕд/мл (= µIU/mL); альт. пмоль/л; коэф.: мкЕд/мл × 6.945 = пмоль/л
- 🔵 **Лаб. референс:** 2.7–10.4 мкЕд/мл (Инвитро); до 25 — некоторые лаб.
- 🟡 **Клин. оптимум:** <10 мкЕд/мл (нет явной ИР)
- 🟢 **Функц. оптимум:** 2–6 мкЕд/мл (Root Functional Medicine, OptimalDX); школа 5–7 мкЕд/мл
- 📝 ⚠️ Самый ранний маркер ИР (раньше чем глюкоза и HbA1c). >10 натощак — гиперинсулинемия.
- **Источники:** [Veri Fasting Insulin](https://www.veri.co/learn/optimal-fasting-insulin-level), [OptimalDX Insulin](https://www.optimaldx.com/research-blog/fasting-insulin)

### 4.4 С-пептид
- **Ед. изм.:** нг/мл / нмоль/л; коэф.: нг/мл × 0.331 = нмоль/л
- 🔵 **Лаб. референс:** 0.78–1.89 нг/мл (Medscape, Инвитро)
- 🟡 **Клин. оптимум:** в референсе; ↓ при СД1, ↑ при СД2/ИР
- 🟢 **Функц. оптимум:** 1.1–1.6 нг/мл — школа
- 📝 Маркер собственной выработки инсулина. Используется параллельно с инсулином для дифференциации СД1/СД2.

### 4.5 HOMA-IR (индекс инсулинорезистентности)
- **Формула:** (Инсулин мкЕд/мл × Глюкоза ммоль/л) / 22.5
- **Ед. изм.:** безразмерный
- 🔵 **Лаб. референс:** <2.7
- 🟡 **Клин. оптимум (международ. исследования):**
  - <1.0 — отличная чувствительность к инсулину
  - 1.0–1.5 — норма
  - 1.5–2.5 — пограничная ИР
  - >2.5 — выраженная ИР (NHANES, метаанализ 2024)
- 🟢 **Функц. оптимум:** ≤1.4 — школа; функциональная медицина <1.0
- **Источники:** [Springer 2024 HOMA-IR](https://link.springer.com/article/10.1186/1743-7075-7-26)

### 4.6 Альфа-амилаза / Липаза 🆕
- **Альфа-амилаза:**
  - 🔵 Лаб. референс: <125 Ед/л; 🟡 Клин. <100; 🟢 Функц. <100 — школа
- **Липаза:**
  - 🔵 Лаб. референс: <60 Ед/л; 🟡 Клин. <50; 🟢 Функц. <50 — школа
- 📝 Маркеры поджелудочной. ↑ обоих — острый/хронический панкреатит; изолированное ↑амилазы — слюнные железы.

---

### 📝 Комментарии к разделу 4 (Углеводный обмен)

**Опорные паттерны для Агента:**
- **Ранняя ИР (за 5–10 лет до диабета):** Инсулин >6 + HOMA-IR >1.5 при нормальной глюкозе и HbA1c.
- **Метаболический синдром (минимум 3 признака):** окружность талии ↑ + ТГ ↑ + ЛПВП ↓ + АД ↑ + глюкоза ↑.
- **СД2 манифестный:** HbA1c ≥6.5% + глюкоза ≥7.0 при двух измерениях.
- **Скрытый СД1 / LADA:** низкий С-пептид при ↑глюкозе у худых взрослых.
- **Реактивная гипогликемия:** инсулин ↑ + глюкоза N или ↓ + симптомы через 2–4 ч после еды.

**Приоритет диагностики ИР по чувствительности (от раннего к позднему):** Инсулин натощак → HOMA-IR → ТГ/ЛПВП → ГТТ с инсулином → Глюкоза натощак → HbA1c.

## 5️⃣ ЖЕЛЕЗО И ОБМЕН ЖЕЛЕЗА

> **Связанный файл:** см. также [`references/clinical_guidelines/iron_deficiency.md`](../../clinical_guidelines/iron_deficiency.md) — полный протокол по ЖДА (BSH 2021, AGA 2024, Минздрав РФ).

### 5.1 Ферритин (Ferritin) ⭐ ключевой маркер
- **Ед. изм.:** нг/мл (= мкг/л)
- 🔵 **Лаб. референс:** ж 13–150 нг/мл; м 30–400 (Инвитро)
- 🟡 **Клин. оптимум:**
  - Дефицит: <30 нг/мл (BSH 2021); <15 (WHO — устаревший)
  - С анемией/симптомами: <45 (AGA 2024)
  - При воспалении: <70 (WHO 2020 поправка)
- 🟢 **Функц. оптимум:** 70–100 нг/мл (Effect Doctors, OptimalDX); школа 60–90
- 📝 ⚠️ Ферритин — реактант острой фазы. При ↑СРБ ферритин может быть ложно нормальным/высоким. Всегда смотреть в паре с СРБ.
- **Источники:** [BSH 2021](https://onlinelibrary.wiley.com/doi/full/10.1111/bjh.19440), [AGA 2024](https://www.cghjournal.org/article/S1542-3565(24)00410-5/fulltext), [Effect Doctors](https://effectdoctors.com/blog/optimum-vs-normal-iron-levels-women/)

### 5.2 Сывороточное железо (Serum Iron) 🔄
- **Ед. изм.:** мкмоль/л / мкг/дл; коэф.: мкмоль/л × 5.585 = мкг/дл
- 🔵 **Лаб. референс:** ж 9–30; м 11–32 мкмоль/л (Инвитро); OptimalDX ж 11–29
- 🟡 **Клин. оптимум:** в референсе
- 🟢 **Функц. оптимум:** 13–25 мкмоль/л (OptimalDX); школа 20–25
- 📝 ⚠️ Сильные суточные колебания (утром выше на 30%). Изолированно НЕ диагностический — только в комплексе с ферритином, TSAT, ОЖСС.

### 5.3 Трансферрин (Transferrin)
- **Ед. изм.:** г/л
- 🔵 **Лаб. референс:** 2.0–3.6 г/л
- 🟡 **Клин. оптимум:** 2.0–3.6
- 🟢 **Функц. оптимум:** 2.5–3.3 г/л — школа
- 📝 ↑ при дефиците железа (компенсация); ↓ при воспалении / печёночной недостаточности.

### 5.4 Коэффициент насыщения трансферрина (TSAT, %Sat) 🆕
- **Формула:** (Железо / ОЖСС) × 100
- **Ед. изм.:** %
- 🔵 **Лаб. референс:** 20–50% (StatPearls, Medscape)
- 🟡 **Клин. оптимум:**
  - Дефицит: <20% (Medscape)
  - Перегрузка: >50%
- 🟢 **Функц. оптимум:** 24–35% (OptimalDX)
- 📝 Один из ключевых маркеров наряду с ферритином. <20% + ферритин <30 → ЖДА; >50% — заподозрить гемохроматоз.
- **Источники:** [OptimalDX TSAT](https://www.optimaldx.com/research-blog/draft-biomarkers-of-iron-status-transferrin-saturation), [Medscape TSAT](https://emedicine.medscape.com/article/2087960-overview)
- 🆕 В школьной таблице отсутствовал — добавлен в master.

### 5.5 ОЖСС (TIBC, общая железосвязывающая способность) 🆕
- **Ед. изм.:** мкмоль/л
- 🔵 **Лаб. референс:** 45–75 мкмоль/л
- 🟡 **Клин. оптимум:** 45–75
- 🟢 **Функц. оптимум:** 45–65 мкмоль/л
- 📝 ↑ при ЖДА (компенсация); ↓ при воспалении, гемохроматозе.

**Опорный паттерн ЖДА для Агента (стадии):**

| Стадия | Ферритин | Железо | TSAT | ОЖСС | Hb | MCV |

## 6️⃣ ВИТАМИНЫ — ЖИРОРАСТВОРИМЫЕ И ГРУППА B

### 6.1 Витамин D, 25(OH)D ⭐ ключевой маркер
- **Ед. изм.:** нг/мл (РФ) / нмоль/л (Европа); коэф.: нг/мл × 2.5 = нмоль/л
- 🔵 **Лаб. референс:** 30–100 нг/мл (Инвитро); глобально 20–100
- 🟡 **Клин. оптимум (Endocrine Society 2024):**
  - Дефицит: <20 нг/мл (<50 нмоль/л)
  - Недостаточность: 20–29 нг/мл (50–75 нмоль/л)
  - Достаточность: ≥30 нг/мл (≥75 нмоль/л)
- 🟢 **Функц. оптимум:** 50–80 нг/мл (большинство источников); школа 60–90 нг/мл (верхний функциональный)
- 📝 ⚠️ Не путать с активной формой 1,25(OH)2D (применяется при ХБП и саркоидозе). Целевой именно 25(OH)D.
- 📝 Сезонные колебания: зимой ↓ на 30–50%; добавки до целевого уровня.
- **Источники:** [Endocrine Society 2024](https://www.endocrine.org/clinical-practice-guidelines/vitamin-d-for-prevention-of-disease), [JCEM 2011 Holick](https://academic.oup.com/jcem/article/96/7/1911/2833671)

### 6.2 Витамин B12 (Кобаламин) ⭐ ключевой маркер 🆕
- **Ед. изм.:** пг/мл (= нг/л) / пмоль/л; коэф.: пг/мл × 0.738 = пмоль/л
- 🔵 **Лаб. референс:** 200–950 пг/мл (UCSF, WebMD); Инвитро 187–883
- 🟡 **Клин. оптимум:**
  - Дефицит: <200 пг/мл (<148 пмоль/л)
  - Серая зона: 200–400 (вероятен функциональный дефицит)
  - Норма: >400 пг/мл
- 🟢 **Функц. оптимум:** 500–1300 пг/мл (Integrative Health Check 2015, Yale Medicine); школа (Чек-лист) «от 500–600»
- 📝 ⚠️ При уровне 200–400 пг/мл проверять holo-TC и MMA (см. ниже) для подтверждения функционального дефицита.
- 📝 Метформин, ИПП, H2-блокаторы → ↓B12. Веганы → группа риска.
- **Источники:** [UCSF B12](https://www.ucsfhealth.org/care/medical-tests/vitamin-b12-level), [Yale Medicine B12](https://www.yalemedicine.org/news/are-you-getting-enough-vitamin-b12)
- 🆕 В школьной таблице отсутствовал — добавлено в master.

### 6.2a Холотранскобаламин (Holo-TC, активный B12) 🆕
- **Ед. изм.:** пмоль/л
- 🔵 **Лаб. референс:** >50 пмоль/л
- 🟡 **Клин. оптимум:** >50 (норма); <35 — функциональный дефицит
- 🟢 **Функц. оптимум:** >70 пмоль/л
- 📝 Самый чувствительный маркер биодоступного B12. Назначается при B12 в «серой зоне» 200–400 пг/мл.

### 6.2b Метилмалоновая кислота (MMA) 🆕
- **Ед. изм.:** нмоль/л (сыворотка) / мкмоль/ммоль креатинина (моча)
- 🔵 **Лаб. референс:** <270 нмоль/л (сыворотка)
- 🟡 **Клин. оптимум:** <270; ↑ при функциональном B12-дефиците
- 🟢 **Функц. оптимум:** <200 нмоль/л
- 📝 Функциональный маркер B12 на клеточном уровне. ↑MMA при норме B12 = функциональный дефицит. Не валидно при ХБП (ложное ↑).

### 6.3 Фолиевая кислота (B9, Folate)
- **Ед. изм.:** нг/мл / нмоль/л; коэф.: нг/мл × 2.266 = нмоль/л
- 🔵 **Лаб. референс:** 3.1–20.5 нг/мл (Инвитро); Medscape 6–14
- 🟡 **Клин. оптимум:** >6 нг/мл (исключение дефицита)
- 🟢 **Функц. оптимум:** >10 нг/мл (школа); RBC-фолат >500 нг/мл (OptimalDX)
- 📝 RBC-фолат (в эритроцитах) точнее сывороточного — отражает запасы за 3 мес.
- 📝 ⚠️ При полиморфизмах MTHFR (C677T, A1298C) лучше принимать **метилфолат** (5-MTHF), а не фолиевую кислоту.
- **Источники:** [CDC Folate](https://www.cdc.gov/mmwr/preview/mmwrhtml/mm6415a5.htm), [Medscape Folate](https://emedicine.microsoft.com/article/2085523-overview)

### 6.4 Витамин B6 (Пиридоксин, PLP) 🔄
- **Ед. изм.:** нг/мл / нмоль/л; коэф.: нг/мл × 4.046 = нмоль/л
- 🔵 **Лаб. референс:** 5–50 мкг/л (= 20–202 нмоль/л) (Medscape); ≥20 нг/мл (РФ)
- 🟡 **Клин. оптимум:** >50 нмоль/л (Bjørke-Monsen 2023); <50 нмоль/л — недостаточен
- 🟢 **Функц. оптимум:** 35–70 нг/мл (140–283 нмоль/л) — школа
- 📝 ⚠️ Чрезмерные дозы (>200 мг/день длительно) → периферическая нейропатия.
- **Источники:** [OptimalDX B6](https://www.optimaldx.com/research-blog/vitamin-biomarkers-vitamin-b6)

### 6.5 Витамин B1 (Тиамин, TPP)
- **Ед. изм.:** нг/мл / нмоль/л
- 🔵 **Лаб. референс:** 70–180 нмоль/л (Mayo, цельная кровь); РФ ≥25 нг/мл
- 🟡 **Клин. оптимум:** 70–180 нмоль/л
- 🟢 **Функц. оптимум:** 35–75 нг/мл (школа); >100 нмоль/л (функц. медицина)
- 📝 ↓ при алкоголизме, диабете, ИР, баритрии. Дефицит → бери-бери, синдром Вернике.

### 6.6 Витамин B2 (Рибофлавин)
- **Ед. изм.:** мкг/л
- 🔵 **Лаб. референс:** ≥4.3 мкг/л
- 🟡 **Клин. оптимум:** >5 мкг/л
- 🟢 **Функц. оптимум:** >6 мкг/л — школа
- 📝 Кофактор для активации B6, B9, методонина → влияет на гомоцистеин.

### 6.7 Витамин B3 (Никотиновая кислота, ниацин)
- **Ед. изм.:** мкг/мл
- 🔵 **Лаб. референс:** ≥0.5 мкг/мл
- 🟡 **Клин. оптимум:** >0.8
- 🟢 **Функц. оптимум:** >1.0 мкг/мл — школа

### 6.8 Витамин B5 (Пантотеновая кислота)
- **Ед. изм.:** мкг/мл
- 🔵 **Лаб. референс:** ≥1.0 мкг/мл
- 🟡 **Клин. оптимум:** >1.5
- 🟢 **Функц. оптимум:** 1.5–2.5 мкг/мл — школа
- 📝 Ключевой для надпочечников и синтеза кортизола.

### 6.9 Витамин B7 (Биотин) 🔄
- **Ед. изм.:** нг/мл / пг/мл; коэф.: нг/мл × 1000 = пг/мл
- 🔵 **Лаб. референс:** 0.05–0.83 нг/мл (= 50–830 пг/мл) (LabCorp); 200–1200 нг/дл (Ulta)
- 🟡 **Клин. оптимум:** >0.2 нг/мл
- 🟢 **Функц. оптимум:** 300–800 пг/мл — школа
- 📝 ⚠️ Высокие дозы биотина (>5 мг/день) **искажают многие гормональные анализы** (ТТГ, ФТ4, тропонин, ХГЧ) — отменять за 72 ч до сдачи!
- **Источники:** [LabCorp B7](https://www.labcorp.com/tests/070097/vitamin-b7), [PMC Biotin Lab Errors](https://pmc.ncbi.nlm.nih.gov/articles/PMC6802814/)

### 6.10 Витамин B8 (Инозит)
- **Ед. изм.:** мкг/л
- 🔵 **Лаб. референс:** ≥60 мкг/л
- 🟡 **Клин. оптимум:** >80
- 🟢 **Функц. оптимум:** 80–120 мкг/л — школа
- 📝 Используется при СПКЯ и ИР (мио-инозит + D-хиро-инозит 40:1).

### 📝 Комментарии к разделу 6 (Витамин D + B-группа)

**Опорные паттерны для Агента:**
- **B12-дефицит:** ↑MCV + ↑MCH + ↓B12 (или 200–400) + ↑MMA + ↑гомоцистеин + ↓Holo-TC + неврологические симптомы.
- **Фолатный дефицит:** ↑MCV + ↓фолаты + ↑гомоцистеин, но без неврологических симптомов (важно отличать от B12).
- **Витамин D дефицит-индуцированные состояния:** ↑ТТГ, ↓кальций, аутоиммунные обострения, депрессия, мышечная слабость.
- **B6 + B9 + B12 (трио метилирования):** все три ↓ → ↑гомоцистеин → риск ССЗ, тромбозов, нейродегенерации.
- **Биотин-интерференция:** если у клиента «странный» ТТГ или ФТ4 — спросить про биотин в комплексах для волос/ногтей.

## 7️⃣ ВИТАМИНЫ — ЖИРОРАСТВОРИМЫЕ A, E, K, C

### 7.1 Витамин A (Ретинол) 🔄
- **Ед. изм.:** мкг/мл / мкмоль/л; коэф.: мкг/мл × 3.49 = мкмоль/л
- 🔵 **Лаб. референс:** 0.3–0.8 мкг/мл (= 1.05–2.8 мкмоль/л); ВОЗ дефицит <0.2 мкг/мл
- 🟡 **Клин. оптимум:** 0.4–0.7 мкг/мл; ВОЗ норма >0.7 мкмоль/л
- 🟢 **Функц. оптимум:** 0.5–0.8 мкг/мл (Lamkin Clinic — функциональная медицина); школа 0.3–0.8
- 📝 ⚠️ Гипервитаминоз А (>1.0 мкг/мл длительно) → токсичность печени, гипотиреоз, гиперлипидемия, тератогенность.
- 📝 У вегетарианцев и при низком жире в рационе часто ↓ (плохая конверсия бета-каротина).
- **Источники:** [OptimalDX Vit A](https://www.optimaldx.com/research-blog/vitamin-biomarkers-vitamin-a), [WHO Vit A](https://nutritionalassessment.org/vitamina/)

### 7.2 Витамин E (Альфа-токоферол)
- **Ед. изм.:** мг/л / мкмоль/л; коэф.: мг/л × 2.32 = мкмоль/л
- 🔵 **Лаб. референс:** 5.5–17.0 мг/л (Mayo, взрослые)
- 🟡 **Клин. оптимум:** >12 мг/л — снижение риска ХБП и онкологии (Science 2023)
- 🟢 **Функц. оптимум:** 13–14 мг/л (новые исследования); школа 15 мг/л
- 📝 Оценивать с поправкой на липиды (соотношение E/общий ХС).
- **Источники:** [Mayo Vit E](https://pediatric.testcatalog.org/show/VITE), [Science 2023](https://www.sciencedirect.com/science/article/pii/S0002916523291686)

### 7.3 Витамин K (K1 + K2) 🆕
- **Витамин K1 (филлохинон):**
  - 🔵 Лаб. референс: 0.10–2.20 нг/мл (LabCorp)
  - 🟢 Функц. оптимум: 0.5–2.0 нг/мл
- **Витамин K2 (MK-7, менахинон):**
  - 🔵 Лаб. референс: 0.12–3.54 нг/мл (PMC 2023, Beijing study)
  - 🟡 Клин. оптимум: >1.0 нг/мл (Lamkin Clinic — для активации остеокальцина и MGP)
  - 🟢 Функц. оптимум: >1.0 нг/мл
- 📝 Школьная таблица указывает «50–900 нг/л, оптимум 600 нг/л» — это значения в **нг/л** (= пг/мл), что соответствует общему витамину K, не K2 отдельно. В master добавлены актуальные K1 и K2 раздельно.
- 📝 K2 + Витамин D + Кальций = синергия для костей и предотвращения кальцификации сосудов.
- **Источники:** [Lamkin K2](https://lamkinclinic.com/vitk2/), [PMC K Reference Ranges](https://pmc.ncbi.nlm.nih.gov/articles/PMC10143736/)

### 7.4 Витамин C (Аскорбиновая кислота)
- **Ед. изм.:** мг/л / мкмоль/л; коэф.: мг/л × 5.68 = мкмоль/л
- 🔵 **Лаб. референс:** 4–15 мг/л (= 23–85 мкмоль/л) (Medscape 0.4–1.5 мг/дл)
- 🟡 **Клин. оптимум:** >5 мг/л; дефицит <2 мг/л (Mayo, ARUP)
- 🟢 **Функц. оптимум:** >8 мг/л — школа; >50 мкмоль/л (функц. медицина)
- 📝 Курильщики, при стрессе, при инфекциях — ↑↑потребности. Конкурирует с глюкозой за всасывание.
- **Источники:** [Medscape Vit C](https://emedicine.medscape.com/article/2088649-overview), [Mayo Vit C](https://www.mayocliniclabs.com/test-catalog/overview/42362)

### 📝 Комментарии к разделу 7 (Жирорастворимые витамины)

**Опорные паттерны для Агента:**
- **Мальабсорбция жиров (БДА, целиакия, СИБР, желчный застой):** одновременное ↓ A + E + K + D + сухая кожа, ночная слепота, остеопороз.

- **Гипервитаминоз А:** головная боль, тошнота, выпадение волос, желтуха ладоней.
- **Витамин C-дефицит (цинга):** кровоточивость дёсен, плохое заживление, синяки, утомляемость.

## 8️⃣ ГОМОЦИСТЕИН И МЕТИЛИРОВАНИЕ

### 8.1 Гомоцистеин (Homocysteine, Hcy) ⭐ ключевой маркер
- **Ед. изм.:** **мкмоль/л** (µmol/L)
- 🔵 **Лаб. референс:** 5–15 мкмоль/л (Cleveland Clinic, NIH); РФ Инвитро 5.5–16.2
- 🟡 **Клин. оптимум:**
  - Норма: 5–10 мкмоль/л (MDPI 2024 рекомендует <10 как порог)
  - Умеренная гипергомоцистеинемия: 10–30 мкмоль/л
  - Промежуточная: 30–100
  - Тяжёлая: >100
- 🟢 **Функц. оптимум:** 5–7 мкмоль/л (PMC NIH); школа <8 мкмоль/л
- 📝 ⚠️ В школьной таблице была опечатка — указано «ммоль/л», правильно **мкмоль/л** (концентрация в 1000 раз ниже).
- 📝 ↑Hcy → риск ССЗ, инсульта, тромбозов, нейродегенерации, остеопороза, осложнений беременности.
- 📝 Кофакторы метилирования: B12 + B9 (метилфолат) + B6 (PLP) + B2 (для активации B6/B9) + холин + бетаин (TMG).
- **Источники:** [Cleveland Clinic](https://my.clevelandclinic.org/health/articles/21527-homocysteine), [MDPI 2024](https://www.mdpi.com/1422-0067/25/22/12295), [PMC NIH Hcy](https://pmc.ncbi.nlm.nih.gov/articles/PMC4566450/)

### 8.2 Расширенная панель метилирования (рекомендуется при ↑Hcy) 🆕

| Маркер | Норма | Оптимум | Назначение |
|---|---|---|---|
| **MTHFR C677T, A1298C** | Дикий тип | Дикий тип | Полиморфизмы метилирования (генетика) |
| **MMA сыворотка** | <270 нмоль/л | <200 | Функциональный B12 |
| **Holo-TC** | >50 пмоль/л | >70 | Активный B12 |
| **SAM/SAH ratio** | >3.0 | >4.0 | Метильный потенциал клетки |
| **Глутатион (восст./окисл.)** | соотн. >9:1 | >10:1 | Антиоксидантный резерв |
| **Цистатионин** | <300 нмоль/л | <250 | Транссульфурация |

- 📝 Расширенная панель показана при: уровне Hcy ≥10 мкмоль/л + анамнезе ССЗ/тромбозов / привычное невынашивание / необъяснимая усталость / нейропатия.

### 📝 Комментарии к разделу 8 (Гомоцистеин и метилирование)

**Алгоритм для Агента при ↑Hcy:**
1. Сначала проверить трио: B12 (+ Holo-TC + MMA при «серой зоне»), фолаты (RBC-фолат), B6 (PLP).
2. Добавить B2 (рибофлавин) — кофактор активации B6 и B9.
3. Если все витамины в норме, но Hcy всё равно ↑ → подозрение на MTHFR полиморфизм → генетика.
4. Холин и бетаин — альтернативный путь снижения гомоцистеина через BHMT.
5. Целевое снижение: <8 мкмоль/л за 8–12 нед.

**Связь с другими разделами:**
- ↑Hcy + ↓B12 + ↑MCV → см. Раздел 1 (ОАК, макроцитарная анемия).
- ↑Hcy + ↑ЛПНП + ↑ТГ → синергия кардиориска (см. Раздел 3).
- ↑Hcy + ↑ТТГ → гипотиреоз снижает метилирование (см. Раздел 10 Порция 4).

## 9️⃣ МИНЕРАЛЫ (микроэлементы)

### 9.1 Магний (Mg) ⭐ ключевой маркер
- **Ед. изм.:** ммоль/л (РФ) / mg/dL (США); коэф.: ммоль/л × 2.43 = mg/dL
- 🔵 **Лаб. референс:** 0.65–1.05 ммоль/л (Medscape, общий)
- 🟡 **Клин. оптимум:** 0.85–1.0 ммоль/л
- 🟢 **Функц. оптимум:** 0.91–1.04 ммоль/л (OptimalDX, для кардиоздоровья); школа 0.8–1.0
- 📝 ⚠️ Сывороточный Mg отражает только ~1% от общего пула в организме. Лучший маркер — **RBC-магний** (в эритроцитах, норма 4.0–6.4 mg/dL = 1.66–2.65 ммоль/л).
- 📝 Симптомы дефицита при норме лаб.: спазмы, бессонница, тревога, ПМС, мигрени, аритмии.
- **Источники:** [OptimalDX Magnesium](https://www.optimaldx.com/blog/magnesium-why-standard-ranges-are-suboptimal), [Medscape Mg](https://emedicine.medscape.com/article/2088140-overview)

### 9.2 Кальций общий
- **Ед. изм.:** ммоль/л / mg/dL; коэф.: ммоль/л × 4.0 = mg/dL
- 🔵 **Лаб. референс:** 2.15–2.65 ммоль/л (UCLA, Cancer Research UK)
- 🟡 **Клин. оптимум:** 2.2–2.55 ммоль/л
- 🟢 **Функц. оптимум:** 2.25–2.55 ммоль/л; школа 2.2–2.6
- 📝 ⚠️ Для точной оценки рассчитывать ионизированный Ca или корректировать по альбумину: Ca скорр. = Ca измер. + 0.02 × (40 − альбумин г/л).
- 📝 ↑Ca + ↑ПТГ → гиперпаратиреоз; ↓Ca + ↓D + ↓Mg — частая комбинация.

### 9.3 Фосфор (P)
- **Ед. изм.:** ммоль/л / mg/dL; коэф.: ммоль/л × 3.1 = mg/dL
- 🔵 **Лаб. референс:** 0.81–1.65 ммоль/л (PMC)
- 🟡 **Клин. оптимум:** 0.87–1.45 ммоль/л
- 🟢 **Функц. оптимум:** 1.0–1.2 ммоль/л — школа
- 📝 Соотношение Ca/P (по сыворотке) — простой маркер риска ССЗ и саркопении. Оптимум: 2.0–2.5.

### 9.4 Цинк (Zn) ⭐ ключевой маркер
- **Ед. изм.:** мкмоль/л / мкг/дл; коэф.: мкмоль/л × 6.54 = мкг/дл
- 🔵 **Лаб. референс:** 11–18 мкмоль/л (= 72–118 мкг/дл) (Инвитро); 7.6–19.9 (OptimalDX)
- 🟡 **Клин. оптимум:** >12 мкмоль/л (>80 мкг/дл)
- 🟢 **Функц. оптимум:** 15–19 мкмоль/л (OptimalDX 99–130 мкг/дл); школа 18 мкмоль/л
- 📝 Лучше оценивать с медью в паре. Норма Zn:Cu = 0.8–1.2:1. ↑Cu + ↓Zn — частая проблема при стрессе, эстроген-доминировании, медных ВМС.
- 📝 Кофактор 300+ ферментов, влияет на иммунитет, кожу, репродукцию, гормоны ЩЖ.

### 9.5 Медь (Cu)
- **Ед. изм.:** мкмоль/л / мкг/дл; коэф.: мкмоль/л × 6.36 = мкг/дл
- 🔵 **Лаб. референс:** 11–22 мкмоль/л (ж выше, эстроген ↑Cu); школа 11–24
- 🟡 **Клин. оптимум:** 12–20 мкмоль/л; дефицит <12 (PMC)
- 🟢 **Функц. оптимум:** 14–20 мкмоль/л; школа 19
- 📝 Параллельно оценивать **церулоплазмин** (норма 200–600 мг/л) для расчёта свободной/связанной меди.
- **Источники:** [PMC Copper Deficiency](https://pmc.ncbi.nlm.nih.gov/articles/PMC12040334/)

### 9.6 Селен (Se) — связь с щитовидкой
- **Ед. изм.:** мкг/л / нмоль/л; коэф.: мкг/л × 12.66 = нмоль/л
- 🔵 **Лаб. референс:** 70–150 мкг/л (Инвитро)
- 🟡 **Клин. оптимум:** 80–120 мкг/л (для активности глутатионпероксидазы)
- 🟢 **Функц. оптимум:** 110–150 мкг/л (Lamkin Clinic, для дейодиназ ЩЖ); школа 90 мкг/л
- 📝 ⚠️ Селен — кофактор конверсии T4 → T3, при дефиците гипотиреоз даже при норме TТГ. Доза 200 мкг/день снижает АТ-ТПО при АИТ.
- 📝 ⚠️ >400 мкг/л длительно — токсичность (потеря волос, ногтей, нейропатия).
- **Источники:** [Lamkin Selenium](https://lamkinclinic.com/selenium/), [PMC Selenium 2021](https://pmc.ncbi.nlm.nih.gov/articles/PMC8145713/)

### 9.7 Хром, Марганец, Йод 🔄
- **Хром (Cr):**
  - 🔵 Лаб. референс: 0.7–28 мкг/л (цельная кровь, PMC)
  - 🟢 Функц. оптимум: 0.1 мкг/мл — школа (= 100 мкг/л); 📝 ⚠️ это очень высокое значение для сыворотки, скорее школа имела в виду цельную кровь
- **Марганец (Mn):**
  - 🔵 Лаб. референс: 4–15 мкг/л (Linus Pauling Institute)
  - 🟢 Функц. оптимум: 10–15 мкг/л — школа
- **Йод (I) — серум:**
  - 🔵 Лаб. референс: 40–92 мкг/л (Инвитро); OptimalDX 49–97
  - 🟡 Клин. оптимум: ВОЗ — медиана йодурии 100–199 мкг/л для детей школьного возраста (популяционная норма)
  - 🟢 Функц. оптимум: в середине референса (школа); 60–90 мкг/л
  - 📝 Йодурия — лучший показатель статуса (моча 100–200 мкг/л).
- **Источники:** [WHO Iodine](https://www.who.int/data/nutrition/nlis/info/iodine-deficiency), [OptimalDX Iodine](https://www.optimaldx.com/research-blog/mineral-biomarkers-iodine)

### 📝 Комментарии к разделу 9 (Минералы)

**Опорные паттерны для Агента:**
- **Магниевый дефицит (клинически распространённый):** норма сыворотки + симптомы (спазмы, тревога, ПМС) → проверить RBC-Mg или назначить пробную терапию (бисглицинат 300–400 мг/день).

- **Йод+селен для ЩЖ:** оба необходимы; при АИТ — селен 200 мкг 3 мес ↓АТ-ТПО.
- **Кальций+D+K2+Mg:** квартет для костной плотности; кальций изолированно без K2 — кальцификация сосудов.
- **Тяжёлые металлы** (если ↑ Cu, Mn, Cr выше границ): рассмотреть анализ волос на токсичные металлы.

- 📝 Важна для детоксикации (фаза 2), синтеза глутатиона, кератина (волосы/кожа), сульфатации гормонов. Источники: яйца, мясо, чеснок, лук, крестоцветные.

## 1️⃣1️⃣ ЩИТОВИДНАЯ ЖЕЛЕЗА

> **Связанный файл:** см. [`references/clinical_guidelines/thyroid_disorders.md`](../../clinical_guidelines/thyroid_disorders.md) (создаётся позже).

### 11.1 ТТГ (TSH) ⭐ ключевой маркер ⚠️ внутреннее разночтение школы
- **Ед. изм.:** мЕд/л (= мкМЕ/мл)
- 🔵 **Лаб. референс:** 0.4–4.0 мЕд/л (Инвитро, Mayo)
- 🟡 **Клин. оптимум:**
  - ETA 2024: оптимум по риску ССЗ и смертности — 60–80 перцентиль популяции ≈ 1.0–2.5 мЕд/л
  - Беременность 1 трим.: 0.1–2.5
  - Беременность 2–3 трим.: 0.2–3.0
- 🟢 **Функц. оптимум:** 0.8–2.5 (Урок 7) / 1.5–2.5 (Чек-лист) — школа
- 📝 ⚠️ Принимаем для master: **0.8–2.5** как первичный функциональный оптимум, **1.5–2.5** как «узкий» оптимум (Чек-лист).
- 📝 ↑ТТГ при норме Т4 → субклинический гипотиреоз; ↓ТТГ + ↑Т4 → гипертиреоз.
- **Источники:** [ETA 2024](https://pmc.ncbi.nlm.nih.gov/articles/PMC11301568/), [PMC TSH Optimal](https://pmc.ncbi.nlm.nih.gov/articles/PMC10866328/)

### 11.2 Т4 свободный (FT4)
- **Ед. изм.:** пмоль/л / нг/дл; коэф.: пмоль/л × 0.0777 = нг/дл
- 🔵 **Лаб. референс:** 10.3–24.5 пмоль/л (Инвитро); Mayo 0.82–1.76 нг/дл (= 10.6–22.6 пмоль/л)
- 🟡 **Клин. оптимум:** середина-верх референса (15–22 пмоль/л)
- 🟢 **Функц. оптимум:** выше середины референса (школа) — 16–22 пмоль/л
- 📝 Неактивная форма, конвертируется в Т3 (печень, почки) при участии селена и цинка.

### 11.3 Т3 свободный (FT3)
- **Ед. изм.:** пмоль/л / пг/мл; коэф.: пмоль/л × 0.651 = пг/мл
- 🔵 **Лаб. референс:** 3.1–6.8 пмоль/л (Инвитро); 2.3–4.2 пг/мл (Mayo)
- 🟡 **Клин. оптимум:** середина-верх референса (4.5–6.5 пмоль/л)
- 🟢 **Функц. оптимум:** середина референса (школа) — 4.5–6.0 пмоль/л
- 📝 Активная форма. ↓FT3 + N FT4 + N TTГ → нарушение конверсии (дефицит селена, цинка, железа; стресс; голод).
- 📝 Соотношение FT3/FT4 (норма ~0.3): ↓ — плохая конверсия; ↑ — гипертиреоз.

### 11.4 Обратный Т3 (rT3) 🆕
- **Ед. изм.:** нг/дл
- 🔵 **Лаб. референс:** 8–25 нг/дл
- 🟡 **Клин. оптимум:** <15 нг/дл
- 🟢 **Функц. оптимум:** <15 нг/дл
- 📝 Маркер «синдрома низкого Т3» (стресс, голод, хроническая болезнь). Соотношение FT3/rT3 (норма >20) — лучший индикатор тканевой активности Т3.
- 🆕 В школьной таблице отсутствовал — добавлено в master.

### 11.5 АТ-ТПО (Анти-тиреопероксидаза)
- **Ед. изм.:** МЕ/мл (= IU/mL)
- 🔵 **Лаб. референс:** <34 МЕ/мл (Инвитро); Cleveland Clinic <5.6
- 🟡 **Клин. оптимум:** <34 МЕ/мл; ↑ — АИТ (Хашимото)
- 🟢 **Функц. оптимум:** «до середины референса» (школа) ≈ <15 МЕ/мл; идеально нулевые
- 📝 Селен 200 мкг/день 3–6 мес может снизить АТ-ТПО на 40–60%.

### 11.6 АТ-ТГ (Анти-тиреоглобулин)
- **Ед. изм.:** МЕ/мл
- 🔵 **Лаб. референс:** 0–40 МЕ/мл (Инвитро); Medichecks <115
- 🟡 **Клин. оптимум:** <40
- 🟢 **Функц. оптимум:** нулевые значения (школа); <20
- 📝 30–50% при АИТ повышены. При раке ЩЖ — маркер рецидива.

### 11.7 АТ-рТТГ (Анти-рецептор ТТГ, TRAb) 🆕
- **Ед. изм.:** МЕ/л
- 🔵 **Лаб. референс:** <1.75 МЕ/л
- 🟡 **Клин. оптимум:** <1.75
- 🟢 **Функц. оптимум:** отрицательные
- 📝 Маркер болезни Грейвса (диффузный токсический зоб). Назначается при гипертиреозе.

### 📝 Комментарии к разделу 11 (Щитовидка)

**Опорные паттерны для Агента:**

| Состояние | ТТГ | FT4 | FT3 | rT3 | АТ-ТПО | АТ-ТГ |
|---|---|---|---|---|---|---|
| Норма | 0.8–2.5 | сер.-верх | сер.-верх | <15 | <15 | <20 |
| Субклинический гипотиреоз | ↑ 4–10 | N | N | N | ± | ± |
| Манифестный гипотиреоз | ↑↑ >10 | ↓ | ↓ | N или ↑ | ± | ± |
| АИТ (Хашимото) | ↑/N | ↓/N | ↓/N | N | ↑↑ | ↑ |
| Болезнь Грейвса | ↓↓ | ↑↑ | ↑↑ | ↓ | ± | ± |
| Синдром низкого Т3 | N или ↓ | N | ↓ | ↑↑ | − | − |
| Резистентность к гормонам ЩЖ | ↑ | ↑ | ↑ | N | − | − |

**Алгоритм Агента при подозрении на гипотиреоз:**
1. ТТГ + FT4 + FT3 + АТ-ТПО + АТ-ТГ — базовая панель.
2. Проверить кофакторы: селен, цинк, железо (ферритин!), йод (моча), вит D.
3. При плохой конверсии (↓FT3, ↑rT3) — поддержка селена 200 мкг, цинка 25 мг, ферритин >70.
4. При АИТ — глютен-free диета, селен, восстановление ЖКТ, D3 ≥50 нг/мл.
