## 🚀 Запуск агента

| Что хочу сделать | Команда |
|------------------|---------|
| Полный анализ клиента | `/consult Фамилия` |
| Простой ответ клиенту (после консультации) | `/client Фамилия` |
| Сравнить «до/после» | `/compare Фамилия` |
| Составить меню | `/menu Фамилия` |
| Записать новое знание | `/learn` |
| Исправить ошибку агента | `/correct` |

Полный список команд — в `AGENT.md`.

## 💻 Cline (агент в VS Code)

| Что хочу | Как сделать |
|----------|-------------|
| Переключить режим | Внизу панели: **Plan** (обсудить) / **Act** (выполнять) |
| Создать новую задачу | Иконка `+` вверху панели Cline |
| Закрыть зависшую задачу | Крестик `✕` справа от заголовка задачи |
| Перезагрузить Cline | `Ctrl + Shift + P` → "Developer: Reload Window" |
| Подтвердить команду | Зелёная кнопка "Approve" |

## 🛠 Git — самое нужное

| Что хочу | Команда (в PowerShell) |
|----------|------------------------|
| Что изменилось | `git status` |
| История последних 10 коммитов | `git log --oneline -10` |
| Отправить на GitHub | `git push` (только после Approve!) |
| Посмотреть, что в файле | `Get-Content имя_файла.md -Encoding UTF8` |

**Правило:** `git push` — только после явного "Approve". Никогда не пушить без проверки.

## 🆘 Что делать если

| Проблема | Решение |
|----------|---------|
| Кириллица в cmd выглядит "кракозябрами" | Использовать PowerShell + `Get-Content -Encoding UTF8` |
| Cline не отвечает | `Ctrl + Shift + P` → Reload Window |
| Потеряла, на каком шаге остановились | Открыть `project/STATUS.md` |
| Не помню, что значит какой-то термин | Открыть `project/GLOSSARY.md` (будет создан позже) |
| Что-то сломала в файле | `git restore имя_файла.md` (откатит к последнему коммиту) |
