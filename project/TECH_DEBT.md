# Тех.долг проекта Agent-Nutri

Реестр отложенных задач, которые не блокируют текущую работу, но подлежат исправлению. Формат: `TD-NNN` — компактное описание, приоритет, контекст, план фикса.

## Легенда приоритетов

- 🔴 **P1** — блокирует работу или искажает метрики; фикс в ближайшую сессию.
- 🟡 **P2** — мешает, но не критично; фикс при следующем касании области.
- 🟢 **P3** — косметика; фикс когда удобно.

## Правила

1. Каждая запись имеет уникальный ID `TD-NNN` (сквозная нумерация).
2. Новые записи добавляются в конец соответствующего раздела (Open / Resolved).
3. При фиксе — переносится в раздел Resolved с датой, сессией и хешем коммита.
4. Ничего не удаляется — история сохраняется.
