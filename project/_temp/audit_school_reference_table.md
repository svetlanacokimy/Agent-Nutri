## 📚 Концепция трёх уровней (важно!)

В международной функциональной нутрициологии и медицине используется **три уровня референсов** — Агент-Нутри должен их различать:

### 1. Лабораторный референс (Lab Reference Range)
Диапазон, в который попадают **95% «условно здоровых» людей** в популяции. Источник: лаборатории (Инвитро, Гемотест, LabCorp, Mayo, Quest). НЕ означает «оптимально», означает «не болен явно».
*Пример: ферритин 15-150 нг/мл (Инвитро).*

### 2. Клинический оптимум (Clinical Optimal Range)
Диапазон, при котором **минимизирован риск болезней** по данным крупных исследований. Источники: BSH, ASH, AGA, NICE, ETA, Endocrine Society, ВОЗ, Минздрав РФ.
*Пример: ферритин ≥30 нг/мл (BSH 2021 — нижний клинический минимум для исключения дефицита).*

### 3. Функциональный оптимум (Functional/Wellness Optimum)
Диапазон, при котором человек **чувствует себя максимально хорошо** и биохимические процессы работают на пике. Уровень функциональной медицины и нутрициологии (= уровень школы российской нутрициологии).
*Пример: ферритин 70-100 нг/мл (Effect Doctors, OptimalDX, школа).*

**Правило для Агента:** при работе с клиентом всегда указывать, на каком уровне идёт оценка, и приоритезировать функциональный оптимум (как делает школа), но не игнорировать клинический минимум.

## 🔴 КРИТИЧНЫЕ ОШИБКИ (исправляем в master-файле)

### 1. Гомоцистеин — неверная единица измерения ✅ согласовано
- **В школьной таблице:** «0-15 ммоль/л», оптимум «<8 ммоль/л»
- **Правильно:** **мкмоль/л** (µmol/L), не ммоль/л
- **Подтверждение:** Cleveland Clinic, MDPI 2024, NIH — норма 5-15 мкмоль/л; оптимум 5-8 мкмоль/л; >10 мкмоль/л — повышенный риск ССЗ и нейродегенерации.
- **Источники:** 
  - https://my.clevelandclinic.org/health/articles/21527-homocysteine
  - https://www.mdpi.com/1422-0067/25/22/12295
- **Действие:** в master-файле использовать **мкмоль/л**, добавить пометку «в школьной таблице опечатка — указано ммоль/л».

### 2. Мочевина — неверная единица в оптимуме ✅ согласовано
- **В школьной таблице:** референс «3.5-7.3 ммоль/л» ✅, оптимум «<5.5 **мкмоль/л**» ❌
- **Правильно:** <5.5 ммоль/л (мкмоль/л — в 1000 раз меньше, нерелевантно для мочевины)
- **Источники:** 
  - NIH NCBI Bookshelf — норма 1.8-7.1 ммоль/л
  - DiaSys Diagnostic — 2.8-7.2 ммоль/л
- **Действие:** заменить «мкмоль/л» на «ммоль/л».

### 3. Билирубин (общий, прямой, непрямой) — единицы корректны
- **В школьной таблице:** все указано в мкмоль/л ✅
- **Примечание:** в Уроке 7 (текст) встречалась опечатка «ммоль/л» — в master-файле использовать строго **мкмоль/л**.

## 🟡 СПОРНЫЕ ЗНАЧЕНИЯ (документируем три уровня)

### 4. Ферритин
- **Школьная таблица (функциональный оптимум):** 60-90 нг/мл
- **Лабораторный референс:** 15-150 нг/мл (Инвитро)
- **Клинический оптимум:** ≥30 нг/мл — нет дефицита (BSH 2021, AGA 2024 использует <45 для анемии)
- **Функциональный оптимум (международный):** 70-100 нг/мл (Effect Doctors, OptimalDX)
- **Вердикт:** школьный оптимум 60-90 нг/мл согласуется с международной функциональной медициной. ✅

### 5. ТТГ
- **Школа (Урок 7):** оптимум 0.8-2.5 мЕд/л
- **Школа (Чек-лист):** оптимум 1.5-2.5 мЕд/л (более узкий)
- **Лабораторный референс:** 0.4-4.0 мЕд/л
- **Клинический оптимум (ETA 2024):** 60-80 перцентиль здоровой популяции ≈ 1.0-2.5 мЕд/л
- **Вердикт:** для master-файла оставляем оба школьных значения. Базовый функциональный оптимум: **0.8-2.5 (У7) / 1.5-2.5 (ЧЛ)**.
- **Источник:** https://pmc.ncbi.nlm.nih.gov/articles/PMC11301568/

### 6. HOMA-IR
- **Школьная таблица:** оптимум ≤1.4
- **Лабораторный референс:** <2.7
- **Клинический пороги:** NHANES (США) 2.5; метаанализ Springer 2024 для МетСиндрома 1.775
- **Функциональный оптимум:** <1.0-1.5
- **Вердикт:** школьный оптимум ≤1.4 соответствует функциональному подходу. ✅
- **Источник:** https://link.springer.com/article/10.1186/1743-7075-7-26

### 7. Витамин D (25(OH)D)
- **Школьная таблица:** оптимум 60-90 нг/мл
- **Лабораторный референс:** 30-100 нг/мл
- **Клинический оптимум (Endocrine Society 2024):** ≥30 нг/мл (≥75 нмоль/л); дефицит <20 нг/мл
- **Функциональный оптимум:** 40-60 нг/мл (большинство источников), школа 60-90 нг/мл (верхний функциональный)
- **Вердикт:** школьный 60-90 нг/мл — это «верхний функциональный» уровень, документируем как есть.
- **Конверсия:** 1 нг/мл = 2.5 нмоль/л
- **Источник:** https://www.endocrine.org/clinical-practice-guidelines/vitamin-d-for-prevention-of-disease

### 8. Витамин B12 — добавляем в master-файл ✅ согласовано
- **В школьной таблице:** отсутствует строка
- **В чек-листе:** «от 500-600 пг/мл»
- **Лабораторный референс:** 200-950 пг/мл (WebMD, UCSF); дефицит <160-200 пг/мл
- **Клинический оптимум:** >300 пг/мл (нет явного дефицита)
- **Функциональный оптимум:** 500-1300 пг/мл (международная функциональная медицина) ✅
- **Конверсия:** пг/мл × 0.738 = пмоль/л (т.е. 500 пг/мл ≈ 369 пмоль/л)
- **Действие:** добавить отдельной строкой в master-файл.
- **Источники:** 
  - https://www.ucsfhealth.org/care/medical-tests/vitamin-b12-level
  - https://www.sciencedirect.com/science/article/pii/S2212958815001226

## 🎯 СТРУКТУРА БУДУЩЕГО master-файла

Файл: `references/methodology/tables/lab_values_master.md`

Каждый показатель = строка с 6 колонками:
1. **Показатель** (название + альт. название/синоним)
2. **Единица измерения** (основная РФ + альт. международная + коэф. конверсии)
3. **Лаб. референс** (Инвитро/Гемотест)
4. **Клинический оптимум** (международные гайдлайны: BSH, ETA, Endocrine Society, NICE, AGA, ВОЗ, Минздрав РФ)
5. **Функциональный оптимум** (школа + международная функциональная медицина: OptimalDX, Effect Doctors)
6. **Источники** (ссылки)

Группировка по 11 категориям: ОАК / Биохимия / Печень / Липиды / Углеводный обмен / Железо / Витамины / Минералы / Электролиты / Щитовидка / Антитела к паразитам.
