# COMMANDS — Полный список команд Agent-Nutri

> Шпаргалка по всем командам-триггерам. Хранится в: project/COMMANDS.md
> Обновлять при добавлении новых команд в AGENT.md.

## ⚠ ГЛАВНОЕ ПЕРЕД ЗАПУСКОМ
- В Cline включить режим **Agent** (не Ask!) — иначе агент не читает файлы.
- Для обезличенных клиентов давать КОД (CL-005), а не фамилию.

## КОМАНДЫ

| Команда | Что делает | Файл на выходе |
|---------|-----------|----------------|
| `/consult CL-XXX` | Экспертный разбор ДЛЯ СПЕЦИАЛИСТА (полный анализ) | `[ДАТА]_consult_expert.md` |
| `/client CL-XXX` | Отчёт ДЛЯ КЛИЕНТА (простым языком, КБЖУ, где купить) | `[ДАТА]_client_report.md` |
| `/compare CL-XXX` | Сравнение динамики до/после | `[ДАТА]_compare.md` |
| `/menu CL-XXX N` | Меню на N дней | `[ДАТА]_menu_Ndays.md` |
| `/intake CL-XXX` | Первичный приём, заполнить анкету | `profile.md` |
| `/links CL-XXX` | Ссылки на покупку назначенных БАД | вывод в чат |
| `/learn [текст]` | Записать новое знание | `learning/new_knowledge.md` |
| `/correct [текст]` | Записать исправление ошибки агента | `learning/corrections.md` |

## ПОРЯДОК РАБОТЫ С НОВЫМ КЛИЕНТОМ
1. `/intake` — собрать данные в profile.md
2. `/consult` — экспертный разбор для вас
3. `/client` — версия для клиента
4. (по желанию) `/menu`, `/links`

## РЕЖИМЫ /consult
- **strict** (по умолчанию) — НЕ запустится без обязательных данных:
  пол, возраст, рост, вес, жалобы, лекарства, курение, алкоголь,
  менструальный статус, физ.активность, диагнозы.
- **fallback** — по команде «работай с тем что есть»:
  сделает разбор при нехватке данных, пометит спорное значком ⚠,
  КБЖУ приблизительно.
