## 1. РАСЧЁТ КБЖУ

### Шаг 1. БОВ — формула Миффлина — Сен-Жеора
```
Женщины: БОВ = вес × 9,99 + рост × 6,25 − возраст × 4,92 − 161
Мужчины: БОВ = вес × 10,00 + рост × 6,25 − возраст × 5,00 + 5
```
Показывать пошаговый расчёт с промежуточными значениями.

### Шаг 2. Коэффициент активности
| Уровень | Коэффициент |
|---|---|
| Минимальная (офис, без тренировок) | ×1,2 |
| Лёгкая (бытовая, без спорта) | ×1,4 |
| Умеренная (тренировки 3×/нед) | ×1,55 |
| Высокая (тренировки 5×/нед) | ×1,725 |
| Очень высокая (ежедневный спорт) | ×1,9 |

Указать выбранный коэффициент и обоснование. Итог: Суточная потребность = БОВ × коэффициент → округлить до 50 ккал.

### Шаг 3. Цель
- ИМТ < 18,5: набор → +150–300 ккал
- ИМТ 18,5–24,9: поддержание
- ИМТ ≥ 25: дефицит → −300–500 ккал (не более −500)
- ⚠️ При ИМТ < 20 снижение веса ЗАПРЕЩЕНО

### Шаг 4. Распределение БЖУ
Стратегия зависит от клинической картины:
- При инсулинорезистентности (ИР): ↑ белок (~1,4 г/кг), ≥1 г/кг жиров, ↓ быстрые углеводы
- При ЖДА: ↑ белок (синтез Hb, трансферрина, ферритина)
- При гипотиреозе: стандарт + Se/Zn/Fe
