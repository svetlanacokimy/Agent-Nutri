# Архив резервных копий (.bak)

**Дата создания архива:** 2026-08-14

Сюда перемещены все `.bak` файлы, накопившиеся за Sessions 40–62 (резервные копии методичек, STATUS, SOURCES_INDEX, LESSONS, TECH_DEBT и др.).

## Правило

- Не восстанавливать файлы отсюда без явной необходимости. Git-история — основной источник восстановления; она надёжнее, чем разрозненные `.bak`.
- Имена файлов содержат исходный относительный путь (разделители `\` и `/` заменены на `_`), чтобы избежать коллизий и сохранить происхождение.
- Журнал перемещения: `_MIGRATION_LOG_2026-08-14.md`.

Сами `.bak` файлы здесь остаются git-игнорируемыми (глобальный шаблон `*.bak.*` в `.gitignore`) — они хранятся только локально. Под git попадают лишь этот README и журнал перемещения; так история сохраняется без раздувания репозитория резервными копиями.
