## Если ты новый агент — начни отсюда

Agent-Nutri Pro — клинический нутрициологический AI-агент. По данным клиента (анализы, профиль, жалобы) он генерирует профессиональную консультацию в двух форматах: экспертном (для нутрициолога) и клиентском (для пациента), опираясь на доказательную медицину и методологию школы нутрициологии.

- **Пользователь:** русскоязычный практикующий нутрициолог, работающий с реальными клиентами. Любая ошибка в логике или цифрах — риск для пациента.
- **Основной язык:** русский для контента и клиентских материалов; английский — только для научных EBM-тегов (см. `project/EBM_STANDARD_v2.0.md`).

## Структура репозитория

Дерево верхнего уровня с назначением каждой папки.

- `project/` — операционная документация: STATUS, TECH_DEBT, LESSONS, ROADMAP, стандарты (включая `EBM_STANDARD_v2.0.md`), плейбуки.
- `v2/` — новая архитектура: HIERARCHY, SOURCES_INDEX, IDENTITY, PIPELINES, STYLE_GUIDE, KNOWLEDGE_PROTOCOL, SELF_LEARNING.
- `references/methodology/` — база знаний по темам (57 файлов методичек).
- `clients/` — клиентские кейсы (профили, анализы, сгенерированные консультации).
- `skills/` — навыки агента (атомарная логика отдельных шагов).
- `scripts/` — рабочие скрипты (`ebm_audit`, `ebm_engine`, `ebm_validator` и др.).
- `scripts/_archive/` — старые одноразовые скрипты (не запускать).
- `learning/` — обучающие материалы и накопленный опыт продукта-агента.
- `source_files/` — исходники PDF/DOC материалов школы.
- `text_extracted/` — извлечённый из исходников текст.
- `project/_archive/backups/` — архив старых `.bak` файлов.
- `project/_temp/` — временные файлы (в `.gitignore`).

## Правила работы для агентов

- Все `.md` файлы — UTF-8 with BOM (исключение: `.gitignore` — без BOM).
- Не создавать markdown-таблицы в файлах `references/methodology/` (TD-006).
- Байт-якорные проверки перед и после правок (TD-010).
- Не коммитить `project/_temp/` и `*.bak.*`.
- Перед правкой EBM-файла — читать `project/EBM_STANDARD_v2.0.md` полностью.
- После сессии — обновлять STATUS.md, LESSONS.md, TECH_DEBT.md.
