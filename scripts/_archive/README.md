# Архив одноразовых скриптов

Сюда будут перемещены одноразовые скрипты (`close_session_NN.ps1`, `normalize_XXX_v1.ps1`, `fix_*.ps1`, `update_*.ps1` и т. п.) в следующих этапах наведения порядка.

**Статус:** папка пока пустая, но готова к приёму скриптов.

## Правило

- Скрипты здесь **не запускать** — они относятся к завершённым сессиям и оставлены только для истории.
- Актуальные рабочие скрипты остаются в `scripts/` (`ebm_audit.ps1`, будущий `ebm_engine.ps1`, `ebm_validator.ps1`).
