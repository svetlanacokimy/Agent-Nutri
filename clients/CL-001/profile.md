## 2. Клиническая картина и патогенез (гипотеза)
Патогенетическая цепь (рабочая модель нутрициолога):
перегиб ЖП -> застой/густая желчь (дисхолия) -> плохое расщепление жиров + слабое обеззараживание ->
дисбиоз (Blastocystis + грибковые споры) -> хроническое воспаление (СРБ, СОЭ, нейтрофилёз) ->
мальабсорбция -> дефициты (Fe, D, B6, B2, Cu, йод) -> замедление конверсии Т4->Т3 -> низконормальные Т3/Т4.
Параллельно: H. pylori-серология положительна (статус активности НЕ подтверждён, см. раздел 6).

## 6. ОТКРЫТЫЕ ВОПРОСЫ И КРАСНЫЕ ФЛАГИ
- ФЛАГ H. pylori: IgG-серология НЕ отличает активную инфекцию от перенесённой (антитела держатся годами). Статус неизвестен. НУЖНО: 13С-дыхательный тест ИЛИ антиген в кале. Если активна -> эрадикация = ЗОНА ГАСТРОЭНТЕРОЛОГА. Риск: каскад Корреа, атрофия. [Ansari 2022 PMID:36034697; Malfertheiner 2022 PMID:35944925; Correa 2012 PMID:22188910]
- ФЛАГ "симптомы очищения": реакция Герксгеймера доказана только для спирохетозов, НЕ для трав против бластоцист. Ухудшение = сигнал пересмотреть схему, НЕ терпеть. [Butler 2017 PMID:28077740]
- Бластоцисты: патогенность спорна (частый бессимптомный носитель) — зона научной дискуссии; лечение симптомного носителя защитимо. [Andersen 2016 PMID:26677249]
- Витамин D: принимает ~6 мес, НЕ пересдан — риск передозировки при продолжении 10000 МЕ. СРОЧНО замерить.
- Перед йодом: сдать селен, цинк, ТТГ/Т3/Т4, йод сыв. Узлы ЩЖ -> ввод йода согласовать с эндокринологом (риск автономии узлов). ЗОНА ВРАЧА.

## 7. СЛЕДУЮЩИЕ ШАГИ
1. Досдать: вит. D, СРБ, ТТГ/Т3/Т4, йод, селен, цинк. Контроль Fe/ферритин/белок (срок подошёл).
2. Уточнить статус H. pylori активным тестом -> при +, к гастроэнтерологу.
